## 5주차
### 맡은 역할 :
개인 프로토타입 제작 및 비교 분석을 통한 메인 프로토타입 시안 개발

### 한 일 :
-팀원들과 함께 GitHub에 가입하고 레포지토리 활용을 위한 기본 환경 확인
-각자 앱 프로토타입 시안을 제작하고, 팀원들의 시안을 비교·분석하여 방향성 검토
-비교 분석 결과, 내가 제작한 프로토타입 시안이 메인 시안으로 채택됨
-채택된 시안을 바탕으로 메인 화면에 사용될 프로토타입을 디벨롭하고 화면 구성 및 UI 개선
-음성 트리거(iOS Siri 단축어/Android) 직접 실험 후 작동검증, 업체 정보 API 가능 범위 조사
-조사 결과를 반영해 일정 조율을 빼고 해결 사례 도서관 + SOS 모드로 범위 확정에 참여

## 6주차
### 맡은 역할 :
메인 프로토타입 UI 및 기능 개선, 사용자 테스트 진행 및 결과 분석

### 한 일 :
- 팀원들과 함께 제작한 프로토타입을 활용하여 참여자 3명을 대상으로 사용자 테스트 진행
- 테스트 과정에서 참여자별 화면 녹화 및 촬영을 통해 사용자의 행동과 이용 흐름 기록
- 녹화 자료를 AI로 분석하여 화면별 체류 시간, 클릭 행동, 기능 탐색 과정 및 사용 중 발생한 문제점 파악
- AI 분석 결과와 사용자 테스트 내용을 팀원들과 공유하고, 프로토타입의 개선점 및 수정 방향 논의
- 긴급모드 및 SOS 관련 화면을 제거하고 하단 탭을 홈, 사례, 커뮤니티, 마이페이지로 재구성
- 해결 단계에서 어려운 용어를 설명하는 기능 추가
- 메시지 작성 및 사진 첨부 UI 개선, 메시지 전송 후 화면 이동 흐름 수정
- 주변 수리업체 검색 및 카카오맵 연결 방식 개선
- 동일한 문제를 다시 확인할 때 기존 기록을 활용하도록 중복 기록 처리 방식 개선
- 내 주소지 설정 및 분석 완료 후 화면 이동 흐름 개선
- 페이지별 프로토타입 화면을 PNG 이미지로 정리하여 GitHub에 첨부

## 7주차
### 맡은 역할 :
초기 UI 스케치 및 디자인 컨셉 스케치, UI 디자인 구현(공동), 3D 에셋 제작 및 수정, 중간고사 발표 자료 제작(공동), iOS 출시 준비 체크리스트 사이트 제작

### 한 일 :
- 메인 홈, 해결 방법 제시 페이지, 커뮤니티 페이지 총 3개 화면의 초기 스케치 제작
- 3D 캐릭터와 오브젝트를 활용한 컨셉, 깔끔한 UI 중심 컨셉의 두 가지 디자인 방향 제안
- 각 컨셉의 시각적 특징과 화면 구성을 비교할 수 있도록 초기 시안 제작
- 팀 회의에서 각자 준비한 스케치를 공유하고, 논의 결과를 바탕으로 UI 디자인 방향 구체화 (공동)

UI 디자인 비주얼 구현 및 수정작업(공동)
- 팀 회의에서 논의한 디자인 방향을 바탕으로 피그마에서 주요 화면 UI 구현 (공동)
- 3D 컨셉을 중심으로 디자인 레퍼런스를 수집하고 메인 홈 화면의 시각적 방향 구체화(공동)
- 브랜드의 개성과 화면의 완성도를 높이기 위해 3D 오브젝트의 질감, 형태, 컬러 등을 조정하고 UI와의 조화 검토

3D 에셋 제작 및 수정
- ChatGPT 이미지 생성 기능을 활용해 앱 화면에 적용할 3D 오브젝트를 직접 생성하고 수정
- 반복적인 이미지 생성과 수정을 통해 유리처럼 투명하고 매끄러운 질감의 3D 오브젝트 제작
- 제작한 3D 오브젝트를 실제 화면에 적용해 UI와의 시각적 일관성 검토 및 보완

중간고사 발표 자료 제작(공동)
- 팀원들과 협업해 중간고사 발표용 PPT 제작 (공동)
- AS-IS·TO-BE, 페르소나 및 시나리오, 앱 플로우차트, 디자인 시안 비교, 개발 계획 및 일정 관련 등의 페이지 제작
- 서비스의 문제 정의부터 디자인 방향과 향후 개발 계획까지 발표 흐름에 맞춰 시각적으로 정리(공동)

iOS 출시 준비 체크리스트 사이트 제작 및 배포
- Claude AI를 활용해 iOS 앱 출시를 위한 단계별 체크리스트 사이트 제작
- 개발 및 출시 준비 과정에서 팀원들이 확인해야 할 작업을 정리해 공유 가능한 형태로 구성
- 제작한 사이트를 팀원들에게 배포해 개발 진행 과정과 출시 준비 사항을 함께 확인할 수 있도록 지원
