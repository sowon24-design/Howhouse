## 6주차
### 사용한 도구: 
chatGPT
### 효과가 있었던 프롬프트: 
대화 내용을 따로 작성해서 넣어주니 해석이 빨랐다.
### 실패한 시도와 배운 점: 
영상을 입력하면 화면은 해석하는데 대화 내용을 잘 인식하지 못했다. 대화 내용을 텍스트로 입력해주면 작업 시간이 훨씬 단축되며 더 정확하다는 것을 알았다. 대화 내용을 AI로 출력해서 몇몇 오타가 있더라도 부정적 영향을 받지 않았다.
### 남은 한계:
같은 내용을 자꾸 반복한다. 내용이 과하게 길거나, 앞선 내용과 별반 다르지 않거나, 이전 질답을 불필요하게 끌어와서 답변을 한다.
