## 6주차
### 맡은 역할 : 
- P01 사용성 테스트 촬영 및 관찰
- 초기 프로토타입 사용성 테스트 문서 정리
### 한 일 : 
- 사용성 테스트 기록: P01의 초기 프로토타입 사용 과정을 촬영하고, 테스트 영상을 팀에 전달하여 테스트 과정과 사용자 반응을 확인할 수 있도록 함
- 사건 단위 관찰 기록 작성: 테스트 중 발생한 주요 행동과 발언을 사건 단위로 정리하여 사용자가 실제로 어떤 행동을 했는지 파악할 수 있도록 기록
- 사실과 해석의 구분: 사용자의 실제 발언·행동 등 관찰 사실과 이에 대한 분석자의 해석을 구분하여 기록함으로써, 주관적인 판단이 관찰 결과와 혼동되지 않도록 함
- 관찰 근거와 재검증 연결: 발견한 문제나 개선점을 관찰 근거와 연결하고, 추가 확인이 필요한 부분을 재검증 대상으로 정리
- 테스트 결과 문서화 및 공유: 테스트 결과에 대한 판정과 문서 반영 사항을 정리하고, 작성한 초기 프로토타입 사용성 테스트 문서를 GitHub 저장소에 업로드
