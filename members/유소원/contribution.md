## 5주차
### 맡은 역할 : 
깃허브 레포지토리 생성 및 기본 설정 구성
### 한 일 : 
- 저장소 및 협업 환경 구축: Howhouse 프로젝트의 GitHub 저장소를 생성하고 팀원을 초대하여 공동 작업 환경을 마련
- 브랜치 관리 기준 설정: main 브랜치를 공식 작업물의 기준 브랜치로 지정하고, 변경 사항이 무분별하게 반영되지 않도록 수정 제한 및 병합 시 승인 절차를 설정
- 프로젝트 자료 공유: 와이어프레임과 초기 프로토타입 이미지를 저장소에 업로드하고, Figma 링크를 함께 정리하여 팀원들이 디자인 자료를 확인할 수 있도록 함

## 6주차
### 맡은 역할 : 
- P01 사용성 테스트 촬영 및 관찰
- 초기 프로토타입 사용성 테스트 문서 정리
### 한 일 : 
- 사용성 테스트 기록: P01의 초기 프로토타입 사용 과정을 촬영하고, 테스트 영상을 팀에 전달하여 테스트 과정과 사용자 반응을 확인할 수 있도록 함
- 사건 단위 관찰 기록 작성: 테스트 중 발생한 주요 행동과 발언을 사건 단위로 정리하여 사용자가 실제로 어떤 행동을 했는지 파악할 수 있도록 기록
- 사실과 해석의 구분: 사용자의 실제 발언·행동 등 관찰 사실과 이에 대한 분석자의 해석을 구분하여 기록함으로써, 주관적인 판단이 관찰 결과와 혼동되지 않도록 함
- 관찰 근거와 재검증 연결: 발견한 문제나 개선점을 관찰 근거와 연결하고, 추가 확인이 필요한 부분을 재검증 대상으로 정리
- 테스트 결과 문서화 및 공유: 테스트 결과에 대한 판정과 문서 반영 사항을 정리하고, 작성한 초기 프로토타입 사용성 테스트 문서를 GitHub 저장소에 업로드

## 8주차
### 한 일 : 
- 화면 디자인 :
  - 분류체계 정립: 문제별 해결 사례를 직관적인 카테고리로 분류하고, 카테고리별 핵심 예시 데이터 구조화. 각 카테고리에 해당하는 아이콘 일부 제작, 각 카테고리에 들어갈 사례 예시 정리
  - 글 입력시 첨부 가능한 사진 예시 구성
  - 마이홈 내에서 확인 가능한 내가 작성한 글, 댓글 단 글, 내가 해결한 문제, 최근 열람한 사례 구현
  - 서비스 아이덴티티를 반영한 핵심 그래픽 요소(소라게, 집 이미지 등) 디자인 참여
- 구현 가능성 검토 :
  - 기본 카메라 앱 연동(Intent/Activity Call) 방식 검토 및 효율화
  - 문제 인식 및 착안: 카카오톡 등 주요 모바일 앱이 사진 첨부 시 스마트폰의 기본 카메라를 호출하여 사용하는 패턴 분석
  - 기술적 검토: 앱 내에 커스텀 카메라(Camera API)를 처음부터 자체 구현하는 대신, OS에 설치된 기본 카메라 앱을 호출(Intent/Activity 연동)하고 촬영 결과물(사진 파일/Bitmap)의 URI 및 데이터를 전달받는 방식 타당성 검토
  - 기대 효과: 카메라 커스텀 개발에 소요되는 공수를 대폭 절감하고, 사용자에게 이미 익숙한 촬영 UX 제공 및 기기별 카메라 호환성 문제 사전 방지
