# B 화면 인터랙션 확인 — 2026-11-01

최신 사용자 체크리스트 기준. PC 브라우저 확인과 Android 실기기 확인은 구분한다.

## 이번 변경

- 의견·문장 선택 시트는 기존 공통 Dialog를 재사용한다. 공통 파일은 수정하지 않았다. B 전용 SolutionSheet가 앱 영역 아래에 위치를 맞추고 내부 스크롤을 잠근다.
- 공통 규칙의 320ms 위로 열기/아래로 닫기·배경 페이드·포커스 복귀·Escape 취소를 사용한다. 모션 감소 설정도 공통 동작을 따른다.
- 의견 입력→완료 안내를 같은 모달에서 전환한다. 시트가 다시 생성되면서 깜박이는 구조를 제거했다.
- 직접 입력 의견은 trim 후 내용이 있어야 보내기가 활성화된다. 일반 사유는 하나만 선택한다.
- 판단 참고는 내용 높이와 화살표 회전을 함께 전환한다.
- 복사 알림은 버튼 위에 겹쳐 표시하며 본문/버튼을 밀지 않는다.

## 코드·자동 검사로 확인

- 데이터/메시지 검사 14개 통과: 활성 53개 사례 조회, 8개 카테고리의 중복 없는 분류, 삭제 사례 제외, 빈 영상/단계, 괄호 속 쉼표, 영상 URL, 이미지 파일 연결.
- 메시지 모델: 수정 블록 해제 시 전체 제거, 재선택 시 기본 순서에 원문 한 번 추가, 다른 블록 수정·독립 단락 보존, 복사 실패/빈 값/성공 구분.
- B02: 기존 사례만 영상 표시, 문의 대상이 없으면 문의 CTA 숨김, 빈 항목 숨김. 생성 결과 전체 흐름의 실제 API 검증은 별도다.
- B02 평가는 하나의 up/down/null 상태로 관리한다. 더보기는 앞선 사용자 결정에 따라 제거된 상태를 유지한다.
- 전체 이동 코드는 기존 통합 담당 구현을 유지했다. 카테고리 경유 뒤로는 B01, 직접 사례 진입 뒤로는 홈이다.
- 최신 요청은 복사 성공 후 **B03 유지**다. README의 예전 ‘복사 후 홈’ 기록보다 이번 기준이 우선한다.

## 남은 확인·연결

- Android 실기기: 키보드 열림 상태의 본문·CTA 접근, Back으로 키보드를 먼저 닫은 뒤 시트/화면 닫기, 시스템 영역 여백.
- 실제 터치: 스와이프 종료 스냅, 세로 스크롤과 가로 카드 조작, 스크롤 취소 시 눌림 해제·오이동 방지, WebView 오버스크롤. 이번 PC 화살표 검사를 터치 검증으로 간주하지 않는다.
- 외부 영상: 링크 URL은 데이터 검사로 확인했으며 실제 영상 재생·외부 앱 왕복은 이번에 수행하지 않았다.
- 생성 결과·분석 경유의 실제 데이터/뒤로 이동은 소원·예슬 통합 흐름과 함께 확인해야 한다.
- 의견 저장 API는 연결되지 않았다. 완료 안내는 UI 동작이며 실제 저장 성공을 보장하지 않는다.
- 클립보드 쓰기 실패는 모델 검사로 확인했다. 실제 OS 권한 거부 상황은 별도 검증이 필요하다.

## 재확인 방법

`npm run dev` → `http://127.0.0.1:5173/#solutions/화장실`에서 사례 선택 후 아쉬워요를 누른다. 닫기/재열기와 공백 입력을 확인한다. 문의 메시지에서도 문장 선택 시트를 열고 취소·적용·복사를 확인한다. 개발 서버 종료는 터미널 Ctrl+C다.

이번 작업으로 commit/push하지 않았다. App.tsx·공통 컴포넌트·전역 스타일·전체 화면 이동 코드는 변경하지 않았다.
