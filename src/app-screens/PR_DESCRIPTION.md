- 홈 카테고리·인기 사례 → B01/B02/B03 연결. 카테고리 경유 B02 뒤로는 B01, 홈·분석 경유 B02 뒤로는 홈입니다. B03 복사 후에는 현재 화면을 유지합니다.
- 샘플 분석의 시작·성공·실패·취소 연결. 재입력 시 글·사진 유지, 홈 이동·새로고침·프로세스 종료 시 초안 초기화.
- 닉네임·최초 설정 완료 여부의 기기 저장, 온보딩/홈 진입, 개발용 초기화 도구.
- Capacitor Android 프로젝트, 시스템 Back 우선순위, 키보드 CTA 위치·모션, 카메라·사진 선택(총 5장) 연결.
- 기존 공통 버튼/홈 눌림 효과와 B03 클립보드 대체 처리·결과 구분 변경 포함. B 담당자는 B03.tsx, message-model.ts 및 관련 검사 변경을 함께 검토해 주세요. 분석 모듈 자체는 변경하지 않았습니다.

## 팀원 적용 방법

자기 변경사항을 먼저 보존한 뒤 병합된 main을 작업 브랜치에 병합합니다. 폴더를 통째로 덮어쓰지 않습니다. npm ci 후 웹은 npm run dev, Android는 npm run android:sync 후 Android Studio에서 실행합니다. 개인 SDK/JDK 경로·서명 키는 공유하지 않습니다.

main 병합은 예슬이 직접 진행합니다.
