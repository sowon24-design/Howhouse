# 소원의 남은 작업 — 2026-11-01

현재 목표는 **소원 PC + USB로 연결한 갤럭시 퀀텀4 Chrome 시연**이다.
사용자는 다음 단계로 무료 팀원 전용 시험 배포 준비를 선택했다. 구성·선행 작업은 [DEPLOYMENT.md](DEPLOYMENT.md). APK/WebView와 외부 실제 배포는 아직 미완료다.
현재 구현: [CURRENT.md](CURRENT.md), 검사 기록: [VALIDATION.md](VALIDATION.md), 실행: [ANDROID_USB.md](ANDROID_USB.md).

## 완료

- 기존 사례 ID 우선 반환, 필요한 경우 새 해결 방법 생성, B02/B03 연결.
- 생성 시 필요한 집주인/전문 업체 문의 문장을 같은 응답에 자동 작성. B03에서 추가 모델 호출 없음.
- 문의 대상별 빈 문장은 거절하고, 필요하지 않은 대상은 빈 배열로 숨김. 편집·복사·화면 왕복 시 내용 유지.
- 답변 암호화 저장, 같은 글·사진·모델·자료 버전 재사용, 중복 요청 합치기, 개발 호출 한도.
- F02 연결 확인 후 복귀, 자동 재분석 없음, 분석 취소와 늦은 응답 무시.
- 사용자 승인대로 프론트 전체 요청과 서버 모델 작업에 각각 **90초 제한** 적용. 시간 초과는 A05, 재입력 시 글·사진 유지.
- 무료 검사 71건과 build/verify:foundations 통과. 서버 시작 시 비용 기록·저장 폴더 쓰기 가능 여부를 확인해 권한 오류를 사전에 알린다. 시간 초과는 가상 시계로 확인해 API 비용을 쓰지 않았다.
- USB 5173/8787 연결 및 폰 경유 서버 health 200 확인.
- 사용자가 폰에서 사진 첨부/카운터, 실패 후 사진 유지, B02/B03, 복사·편집 유지, F02 복구 후 사진 유지를 확인.
- 폰에서 관련 없는 노트북 모서리 사진으로 실제 분석 실패 화면 확인.
- 제공된 배수구 사진 + ‘물이 잘 내려가지 않는다’는 테스트 가정으로 PC 실제 분석에서 욕실·수도:2 반환, 원본 해결 방법 표시.
- 저장된 실제 GPT 문 경첩 생성 결과를 다시 불러와 B03 자동 문의 본문 표시 확인. 추가 유료 호출 없음.

## 비용 상태

누적 개발 분석 유료 시도 **8/10회**, 새 분석은 **2회 남음** (이번 점검 시 로컬 기록 기준).
이는 호출 횟수이며 달러 잔액을 조회한 값이 아니다. 실제 금액은 OpenAI Usage/Billing에서 확인한다.
저장 답변 재사용·무료 샘플·연결 확인·자동 검사는 모델 호출을 소비하지 않는다.
새 사진/글은 새 호출일 수 있으므로 불필요한 반복 평가를 하지 않는다.

## 시연 전 남은 확인

1. 폰에서 실제 사진 → 분석 중 → 해결 방법 표시를 사용자가 확인했고 내용도 정확하다고 보고했다. 해당 사례의 폰 성공 확인 완료. 전체 상황의 정확도 보증은 아니다.
2. PC 서버와 Vite가 실행되고 USB 두 포트가 연결됐는지 확인한다. 시작/종료 방법은 ANDROID_USB.md 참조.
3. 시연용 글·사진은 고정해 저장 답변을 재사용한다. 글만/사진만 등 새로운 조합은 별도 유료 요청일 수 있다.

90초 경계·늦은 응답은 자동 검사 완료이며, 실기기에서 실제로 90초를 기다리는 추가 유료 검사는 하지 않았다.
현재 소수 사례 확인은 전체 정확도나 출시 준비 완료를 뜻하지 않는다.
