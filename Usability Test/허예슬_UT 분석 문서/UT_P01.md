## 한눈에 보기

- 참여자는 과업 설명이 끝나자 홈의 **'사진으로 보여주기'**를 골랐다. 1:20에 해결 방법 화면에 도착했고, 1:49에 단계 1~4를 모두 확인했다.
- 단계 3 '연결부 너트를 손으로 조이거나 패킹을 교체해요'에서 16초 머물렀다. 이때 **"텍스트로만 돼 있으면 잘 어려울 것 같아"**라고 말했다 (1:37).
- 이후 업체 찾기, 메시지 보내기, 음성 입력, 커뮤니티, 긴급 모드, 사례 카테고리를 모두 써 보았다. 끝났다는 선언은 없었다.
- 커뮤니티에서 **새 글 작성 화면을 세 번 열었다 닫으며**, "해결점이 안 보이면 커뮤니티에 글을 쓰는 흐름인가요?"라고 물었다 (3:08~3:34).
- 홈과 긴급 모드를 **네 번 오가며** 입력 화면을 비교했고, "굳이 여기랑 이거 두 개를 할 필요"라고 말했다 (4:23~4:47).
- 마지막 약 1분 동안 홈·사례 탭·마이를 15번 넘게 오가며 비교했다. 이후 **"사례 탭의 카테고리를 홈 아래에 두면 페이지를 굳이 안 나눠도 될 것 같다"**고 제안했다 (6:34~6:56).
- 음성 입력에서 아무 말도 인식되지 않았는데 분석이 진행되어, 과업과 다른 **'배수구에서 냄새가 나요'** 결과가 나왔다 (3:49~3:55).

## 0. 기록 기준

### 시간 보정

- **기준 시간은 화면 녹화**다. 이 문서의 모든 시각은 화면 녹화 시간이다.
  - P02·P03 문서는 손 촬영 영상이 기준이었다. P01은 손 촬영이 과업 설명이 끝난 뒤에 시작되어서, 과업 설명부터 담긴 화면 녹화를 기준으로 삼았다.
- **스크립트 시각 ≈ 화면 녹화 시각** (오차 ±5초). 보정 없이 그대로 맞는다.
  - 근거: 화면과 발언 내용이 맞는 지점을 기준으로 삼았다.
    - 단계 3 '연결부 너트' 화면(1:31~1:46)과 "연결부 노트(→ 너트)를 조이거나…"(스크립트 01:37)
    - 새 글 작성 화면(3:08~3:34)과 커뮤니티 글쓰기 흐름 질문(스크립트 03:17)
    - 홈 ↔ 긴급 모드 반복(4:23~4:47)과 "굳이 여기랑 이거 두 개를…"(스크립트 04:29)
    - 홈·사례·마이 반복(6:08~7:03)과 "여기랑 홈이랑 좀 비슷한 것 같아요"(스크립트 06:34)
  - 스크립트 00:00에 진행자가 과업 설명을 시작하고, 01:04쯤 설명이 끝난다. 참여자의 첫 탭은 1:01이다.
- **손 촬영 = 화면 녹화 − 약 42초** (오차 ±1초). 손 촬영 시각에 42초를 더하면 화면 녹화 시간이 된다.
  - 근거: 카메라 스캔 시작 손 0:20 / 화면 1:02, 분석 중 화면 손 0:30 / 화면 1:12, 음성 녹음 손 1:40 / 화면 2:21

### 제외한 것

- **인스타그램 알림**: 3:41~3:43에 화면 상단에 인스타그램 알림 배너가 표시됨 (화면 녹화로 확인). 실제 휴대폰의 알림이므로 화면 전환과 체류 시간 계산에서 제외했다. 참여자가 알림을 누른 장면은 없다.
- **카카오톡 알림**: 화면 녹화에서는 확인되지 않았다.

### 표기

- `[확실]` 화면 문구가 보여 확인됨 / `[추정]` 일부만 보이거나 앞뒤 맥락으로 판단함
- `(→ ○○)` 음성 인식 오류의 추정 원문 / `(→ ?)` 원래 말을 추정할 수 없음
- `[시점 추정]` 스크립트가 덩어리 단위라 문장별 정확한 시점은 확인되지 않음
- 화면 녹화에는 터치 표시가 없다. 그래서 '들어온 방법'은 **화면 변화와 손 촬영을 함께 보고 판단**했으며, 직접 눌린 장면이 보이지 않으면 [추정]으로 남겼다.

### 참고 · 관찰 메모

- **'최근 확인한 문제'의 정답 카드**: P02와 마찬가지로 시작 화면에 '싱크대 아래에서 물이 새요' 카드가 있었다. 하지만 P01은 이 카드를 쓰지 않고 '사진으로 보여주기'를 골랐다 (E-01).
- **입력 방식 세 가지 모두 정상 동작**: 사진(1:02), 음성(2:20), 긴급 음성(4:57)이 모두 '싱크대 아래에서 물이 새요'를 맞게 찾아냈다. 직접 입력은 열어만 보고 쓰지 않았다 (2:45).
- **카테고리의 긴급 항목**: 화장실 카테고리에서 '변기 물이 역류해요 [긴급]'을 누르면 문제 상세가 아니라 바로 긴급 단계로 이동했다 (E-11). 의도된 동작인지 팀에서 확인이 필요하다.
- **긴급 단계 건너뛰기**: 긴급 1단계에서 3단계로 4초 만에 넘어갔다 (E-10). 2단계 '전기 제품을 치우세요'를 실제로 봤는지는 확인되지 않는다.
- **사용 의향**: "자취를 하는데 AI 보통 서치를 하는데 좀 있으면 좋을 것 같아요." (E-13)
