## 한눈에 보기

- 참여자는 **입력 단계를 거치지 않고** 홈의 '최근 확인한 문제' 카드를 눌러 0:57에 바로 해결 방법 화면에 도착했다. 핵심 흐름인 '문제 입력 → 파악'은 과업 중에 검증되지 않았다.
- 해결 단계 1~4를 차례로 확인하고 1:22에 **'모두 확인했어요'까지 눌렀다**. 그 뒤 비슷한 사례, 직접 입력, 메시지 보내기, 사진, 긴급 모드를 모두 써 보았다.
- 문제 상세에서 '더 보기'로 들어간 커뮤니티는 **지금 문제로 걸러진 목록**이었고, 참여자는 관련 글 두 개를 읽었다.
- 반면 나중에 **하단 탭으로 들어간 커뮤니티는 필터가 풀린 전체 목록**이었다. 참여자는 카테고리 칩과 정렬을 바꿔 가며 약 40초 동안 찾다가 관련 없는 보일러 글을 열었다 (4:17~4:55).
- 긴급 모드를 끝낸 뒤 **'처음 단계부터 다시 보기'로 같은 흐름을 한 번 더 진행**했다 [추정]. 이후 "어떤 기준으로 긴급인 건지" 모르겠다고 말했다 (4:02).
- 끝났다는 선언이 없어 체크포인트 3과 최종 판정은 비워 두었다.

## 0. 기록 기준

### 시간 보정

- **기준 시간은 손 촬영 영상**이다. 이 문서의 모든 시각은 손 촬영 영상 시간이다.
- **손 촬영 0:00 = 스크립트 01:45** (오차 ±2초). 스크립트 시각은 손 촬영 시간에 1:45를 더하면 된다.
  - 근거: 진행자 설명이 0:50에 끝나고 참여자의 첫 발화(스크립트 02:37)가 이어진다. 이후 발화 구간도 03:56→2:11, 04:46→3:01, 05:47→4:02로 영상의 음성 구간과 맞는다.
- **화면 녹화 = 손 촬영 + 약 1초** (오차 ±1초). 화면 녹화 시각에서 1초를 빼면 손 촬영 시간이 된다.
  - 근거: 화면 전환 시점 6곳을 맞춰 보았다.
    - 홈 → 문제 상세: 손 0:57 / 화면 0:58
    - 분석 중 화면: 손 2:16 / 화면 2:17
    - 홈 복귀: 손 2:44 / 화면 2:45
    - 긴급 모드 진입: 손 3:26 / 화면 3:27
    - 커뮤니티 진입: 손 4:17 / 화면 4:18
    - 홈 복귀: 손 4:56 / 화면 4:57
- 과업 문구를 읽기 시작한 정확한 시점은 단어 단위로 확인할 수 없었다.

### 제외한 것

- **카카오톡 알림**: 약 3:06~4:33에 화면 상단에 알림 배너가 표시됨 (화면 녹화로 확인). 실제 휴대폰의 알림이므로 화면 전환과 체류 시간 계산에서 모두 제외했다. 참여자가 알림을 누른 장면은 없다.
- **화면 녹화 마지막 5:00~5:01**: 녹화를 끝내려고 제어 센터를 연 장면이라 제외했다.

### 표기

- `[확실]` 화면 문구가 보여 확인됨 / `[추정]` 일부만 보이거나 앞뒤 맥락으로 판단함
- `(→ ?)` 음성 인식 오류로 보이지만 원래 말을 추정할 수 없음
- `[시점 추정]` 스크립트가 덩어리 단위라 문장별 정확한 시점은 확인되지 않음
- 화면 녹화에는 터치 표시가 없다. 그래서 '들어온 방법'은 **화면 변화와 손 촬영을 함께 보고 판단**했으며, 직접 눌린 장면이 보이지 않으면 [추정]으로 남겼다.

### 흐름 요약

```
홈 ─(최근 확인한 문제)→ 문제 상세 (단계 1~4 → '모두 확인했어요')
  → 커뮤니티 (지금 문제로 필터됨): 글 A → 목록 → 글 B → 목록
  → 홈 → 직접 입력 → 분석 결과 → 문제 상세 → 메시지 만들기 → 보내기 (시연)
  → 홈 → 사례 탭 → 사진 → 분석 결과 → 문제 상세
  → 긴급 모드 (카메라 → 1·2·3단계 → 완료) → '처음 단계부터 다시 보기' → 반복
  → 문제 상세 → 커뮤니티 (필터 없음): 칩·정렬 변경, 무관한 글 열람 → 홈
```

### 참고 · 긍정 반응

문제는 관찰되지 않고 기대 발언만 있었던 기능:
