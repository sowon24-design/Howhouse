### 2.2 포함·제외

- 대상은 Android이며 기존 AGENTS.md의 하이브리드 방향을 유지한다. 웹은 React + TypeScript + Vite로 구현하고 추후 Android WebView에서 실행한다. 서버·모델·DB 제품은 미정이다. Android 시간·배터리·키보드 등 시스템 UI를 웹에 복제하지 않는다.
- 글만, 사진만, 글+사진을 사용한 문제 입력을 지원한다. 앱의 음성 기능은 삭제한다. 키보드 자체 기능의 노출 여부를 앱이 제어한다고 가정하지 않으며, 음성 입력을 앱 기능으로 안내·수집하지 않는다.
- ‘다른 자취생 이야기’는 기능·디자인 모두 제외한다. 실제 Figma 삭제 작업은 이번 문서 작업에서 하지 않았다.
- 커뮤니티, SOS·음성 호출, iOS, 주변 업체 검색·카카오맵 API, 예약·중개·전화·자동 메시지 전송, 리뷰·가격 기능은 제외한다.
- 문의 버튼이 없는 사례에서 해결하지 못한 경우, 별도의 후속 도움 기능은 제공하지 않는다. 사용자에게 무례한 표현을 화면 문구로 사용한다는 뜻은 아니다.
- 최근 확인 문제·우리 집 문제 기록은 현재 범위에 추가하지 않는다. 유지 여부는 Q13에 남긴다.

### 4.2 E01~E02 최초 소개

- [확정] E01 ‘시작하기’ → E02-1. E02-1 ‘다음으로’ → E02-2 → E02-3 → E03-1.
- [확정] 소개의 X 기능은 없다. 건너뛰기 기능을 추가하지 않는다. 기존 디자인의 X 표시 자체를 숨길지 여부는 Q16에서 확인한다.
- [확정] 소개 도중 앱을 종료하면 다음 실행에 이어서 보여준다. 설정 완료 후에는 F01→A01.
- [확정] 소개 진행 표시의 파란 긴 네모는 길이가 늘고 줄어드는 부드러운 움직임을 사용한다.
- [사용자 확인 필요] 소개 화면의 뒤로 화살표와 Android 뒤로가기 목적지, 이어보기의 정확한 저장 시점은 Q01·Q02.

- [PRD] 문의하기에서는 이메일 복사. 이메일 앱 자동 실행·발송 아님.
- [확정] 실제 이메일·운영 정보·약관·개인정보 처리방침은 추후 수정 예정. 현재 임시 문구를 최종값으로 취급하지 않는다.
- [사용자 확인 필요] 현재 출시 섹션에는 D13이 없으며 다른 전체 화면 영역의 D13 로그아웃을 최신 메뉴로 편입하지 않는다. D13의 출시 범위·대응 메뉴, 외부 링크 실패·복귀 상태·이메일 복사 피드백은 Q12·Q16으로 보류한다.

### 5.2 저장 사례의 연락 화면 분기

| S 집주인 | T 전문 업체 | B02 | 문의 버튼 후 | 앞선 시트 조회 수 |
| --- | --- | --- | --- | ---: |
| 있음 | 있음 | 문의 작성 + 완료 (`472:13728`) | B03 집주인/전문 업체 탭. 집주인 `472:16236`, 전문 업체 `472:16668` | 47 |
| 있음 | 없음 | 문의 작성 + 완료 (`472:13728`) | 집주인 전용 `472:17430`, 문장 U~X | 3 |
| 없음 | 없음 | 완료만 (`472:15889`) | 문의 기능 없음 | 7 |
| 없음 | 있음 | 사용자 설명상 발생하지 않음 | 전문 업체 전용 화면 임의 생성 안 함 | 0 |

[시트 확인] 총 57개. 집주인 전용은 사례 3(곰팡이가 생겼어요), 51(집에서 꿉꿉하고 눅눅한 냄새가 나요), 53(집에 있으면 기침, 비염, 가려움 등이 심해져요). 이는 앞선 조회 시점의 데이터이며 향후 변경을 금지하는 규칙은 아니다.

연락 버튼은 H열 책임 주체가 아니라 S/T 기준이다. T만 생기는 예외 데이터·공백뿐인 셀의 판정은 Q09. 개인 맞춤 LLM 경로에는 직접 S/T가 없으므로 동일 UI를 고를 결과 조건이 추가로 필요하다.

### 5.4 영상 데이터의 남은 문제

앞선 조회는 표시 글자 외 셀 링크도 확인했다. 링크를 제목으로부터 추측해 만들지 않는다.

| 상태 | 셀·사례 번호 |
| --- | --- |
| 한 셀에 URL 2개 | `욕실·수도!R11`, 사례 10 |
| 제목만 있고 URL 미확인 | `욕실·수도!R12/R14/R15` 사례 11/13/14, `난방·전기!R11` 사례 24, `해충·곰팡이!R3` 사례 45 |
| 비어 있음 | `가전!R5` 사례 32, `해충·곰팡이!R4/R11/R12` 사례 46/53/54 |
| 제목이지만 실제 링크 있음 | `욕실·수도!R13`, 사례 12. 제목만 보고 누락으로 분류하지 않음 |

URL 보완, 영상 2개 중 선택, 빈 영상의 영역 표시 규칙, 썸네일 출처는 Q06·Q09.

## 11. 남은 결정·자료 — 코딩 단계 추가 전달

사용자 요청에 따라 아래 항목은 지금 질문을 반복하지 않고 보류하되, 해당 구현을 시작하기 전에 반드시 사용자에게 알린다. 팀원이 담당할 수 있으므로 임의 확정하지 않는다. 확인된 새 화면 정보는 3.1절에 반영했다.

### 11.1 화면·콘텐츠 자료

1. **A05 버튼 동작**: 디자인·문구·노드 확인 완료. 
2. **의견 완료 바텀시트 세부 동작**: 디자인·문구·노드 확인 완료. 
3. **최초 메시지 본문**: 사례별 집주인/전문 업체 별도 본문, 제공 위치. U~AB를 자동 연결하는 방식은 사용하지 않음.
4. **해충·곰팡이 사례별 구분** 및 운영자 선정 인기 문제 목록.
5. **최종 약관·개인정보 처리방침·운영 이메일·운영 정보·Notion URL**, 영상 누락 URL·복수 영상 선택·썸네일.
6. **D13 출시 포함 여부**, 카테고리 위치 A01/A02 최종 확인, X 표시 제거 여부. E04-2·E04-3 이름/노드는 최신 Figma로 확인 완료.

### 11.2 동작 세부 기준

1. **닉네임**: 오류를 처음 표시하는 시점, 앞뒤 공백 자동 정리, 공백 외 문자 수 계산·저장 실패. 공백 1개=1자, 공백만 입력 오류, 오류 시 CTA 비활성·진행 불가는 확정.
2. **분석**: 제한 시간·FAIL 조건·LLM 응답 항목·위험/분류 불가 처리, 개인 맞춤의 문의 대상 결정. 분석 취소 후 화면과 중단 응답 처리.
3. **메시지**: 최초 탭, 별도 본문에 선택 문장을 추가/교체하는 규칙, 직접 편집 보존, 바깥 탭 시 미적용 선택 취소 여부.
4. **뒤로·복구**: 작성 화면/해결 화면/마이의 뒤로 목적지, 키보드 우선 닫기, 오프라인 직전 작업·스크롤·단계 복구.
5. **책임·단계·평가**: 판단 참고 초기 접힘 여부, 첫 단계 이전 버튼, 두 평가 동시 선택·상태 보존, 맞춤 단계 개수.
6. **사진·수집**: 파일 규격·권한 재거부·첨부 실패, 글/사진/닉네임/동의/의견 보관·삭제·외부 제공.
