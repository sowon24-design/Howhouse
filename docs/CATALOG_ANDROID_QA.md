## 판정과 범위

catalog QA의 Android 검증을 완료하여 androidVerified=true로 기록했다. 이는 이 QA 버전의 기능 검증이며 업로드 키로 서명한 최종 Release AAB의 설치·인증서 검증이나 Play 승인까지 완료했다는 뜻은 아니다. 현재 APK는 debug 서명·별도 QA ID이므로 Play에 제출하지 않는다. preflight의 preview-assets-only는 의도된 출시 차단이다.

초기화는 QA 앱의 catalog 설정만 지운다. 기존 앱/서버 자료를 조회·삭제하지 않았다. 실서버 배포·DB 변경·main 병합·Play 제출을 수행하지 않았다.

최종 서명 AAB 생성 후 패키지·버전·서명 인증서·최종 Manifest와 기본 구동을 다시 대조하고, 스토어 자산/설문·비공개 테스트·프로덕션 액세스 순서로 진행한다.
