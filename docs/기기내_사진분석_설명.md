# 사진을 휴대폰 안에서만 분석하려면

2026-11-09. 이번 버전은 글 기반 사례 검색만 제공한다. 아래는 후속 기능의 설명이며 사진 분석 구현 완료를 뜻하지 않는다.

## 어떤 원리인가요?

기존 방식은 사진을 서버와 해외 AI에 보내 해석을 부탁하는 방식이다. 기기 내 분석은 사진을 보는 작은 프로그램과 학습된 모델 파일을 앱에 넣고 휴대폰의 계산 장치로 실행한다. Supabase나 로그인은 필요하지 않다. 해외에서 만든 도구라도 사진을 해외로 보내는지 여부는 별도 문제다. 모델 이용 약관·배포 라이선스와 학교·기관 내부 정책은 따로 확인한다.

예를 들어 사진에서 '배수구'나 '벽의 얼룩' 같은 관찰 가능한 특징을 찾아 관련 사례를 제안할 수 있다. 사진 한 장으로 배관 내부 누수 원인, 보일러 고장, 곰팡이 종류를 확정하는 것은 목표로 삼지 않는다. 보이지 않는 문제는 글로 증상을 추가하고 사용자가 사례를 선택하게 한다.

## 무엇을 준비해야 하나요?

1. 범위 결정: 처음에는 구분 가능한 몇 가지 장면만 대상으로 한다. 어떤 문제든 알아보는 기능으로 약속하지 않는다.
2. 모델 선택: 기존 이미지 모델을 평가한 뒤 부족하면 우리 범위의 사진으로 추가 학습한다. 모델을 처음부터 전부 만드는 것만이 방법은 아니다. Android 실행 도구의 한 예는 LiteRT다.
3. 사진 자료: 이용 권한이 확보된 사진에 정답 표시를 붙인다. 배수구·얼룩·정상 벽 등 다양한 조명·각도·기종·배경을 포함하고 얼굴·주소 등 불필요한 개인정보를 제외한다. 앱 사용자의 사진을 몰래 학습 자료로 모으지 않는다. 사례 대표 일러스트 몇 장으로 실제 집 사진의 정확도를 검증할 수 없다.
4. Android 연결: React 화면에서 사진 선택 → Android에서 모델 실행 → 후보 결과만 화면으로 반환하는 연결이 필요하다. 외부 AI로 자동 우회하지 않는다. 모델을 앱에 포함하면 첫 실행에도 다운로드 없이 사용할 수 있지만 앱 크기가 커질 수 있다.

공식 기술 설명: [LiteRT 개요](https://developers.google.com/edge/litert/overview), [Android 실행](https://developers.google.com/edge/litert/android).

## 정확도는 어떻게 확인하나요?

학습에 쓰지 않은 별도의 사진으로 평가한다. 같은 집·같은 물체의 비슷한 사진이 학습과 평가에 동시에 들어가 점수가 부풀려지지 않게 나눈다. 전체 정답률뿐 아니라 문제별 오인식, 정상 사진을 고장으로 오인하는 비율, 아예 지원하지 않는 사진을 거절하는지, 흐린 사진을 다시 요청하는지도 본다. 충분하지 않으면 '판단하기 어려워요'로 돌아가야 한다.

실제 저사양 Android 기기에서도 응답 시간·메모리·발열·앱 종료·취소·재진입을 확인한다. 특정 정확도 수치는 아직 측정하지 않았으며 출시 기준은 실제 평가 후 정한다. 안전에 영향을 주는 안내는 사람이 검토한다.

## 사진을 보내지 않고 저장하지 않는다는 건?

사진은 분석 중 메모리에서 읽어야 한다. 선택 도구가 임시 파일을 만들 수도 있으므로 '사진이 어디에도 전혀 남지 않는다'고 약속하면 안 된다. 앱이 만드는 임시 복사본·캐시를 파악하고 정상 완료·실패·취소·재실행 때 정리한다. 갤러리의 사용자 원본 사진은 삭제하지 않는다. 사진·썸네일·인식 결과를 로그·백업·오류 수집 도구에 넣지 않는다.

비행기 모드 동작 확인에 더해 네트워크 기록으로 사진·분석 결과가 외부로 전송되지 않는지 확인한다. 모델과 라이브러리의 원격 분석·자동 대체 처리·진단 통신을 조사한다. 앱 파일·캐시도 점검한다. 비행기 모드에서 된다는 사실 하나만으로 평소 외부 전송이 없다고 증명되지는 않는다.

## 동의창만 있으면 되나요?

아니다. 안내와 실제 동작이 같아야 한다. 사진 선택 권한, 개인정보 처리의 법적 근거, 외부 전송 여부는 구분한다. 온디바이스 처리라고 개인정보 보호 의무가 모두 없어지는 것도 아니다. 실제 구현과 적용 근거를 검토한 뒤 안내·동의 필요 범위를 정한다. 향후 안내 예시는 '선택한 사진은 기기 안에서만 분석하며 서버로 전송하거나 별도로 보관하지 않아요'이며, 검증 전에는 이 문구로 기능을 제공하지 않는다.

이번 결정: 사진 분석은 후속 작업으로 두고 글 검색을 먼저 제공한다.
