# 개인정보 및 데이터 관리

## 기기에 저장하는 정보

닉네임, 초기 설정, 소개 진행 위치와 연령 확인값은 기기에 저장합니다. 서버 인증을 이용한 경우 임시 인증 세션도 기기에 남을 수 있습니다. 질문과 편집 중인 문의 문구는 실행 중에 유지하며 별도로 공개하지 않습니다.

## AI 분석과 서버 저장

글과 선택한 사진은 분석 서버를 거쳐 OpenAI API로 전송됩니다. 기존 사례가 적합하면 원래 사례를 보여 주고, 없으며 정보가 충분하면 해결 방법과 문의 문구를 생성합니다. 원본 글·사진을 어쩌집 DB에 별도로 저장하지 않지만 생성된 답변에는 입력 내용이 포함될 수 있습니다.

암호화한 답변·평가·의견·신고, 임시 계정, 사용량과 동의·철회 기록은 서버에서 관리합니다. 제공업체의 접속·보안 기록은 별도 기준을 따릅니다.

## 동의 철회와 서버 데이터 삭제

마이 페이지의 ‘동의 철회·서버 데이터 삭제’에서 AI 분석 동의를 철회하거나 내 서버 데이터 삭제를 요청할 수 있습니다. 동의하지 않거나 철회해도 준비된 카테고리 사례를 볼 수 있습니다.

철회는 이후 AI 분석을 중단하는 것이며 이전 자료 전체를 지우는 요청과는 다릅니다. 서버 삭제는 임시 계정과 연결된 답변·호출·평가·의견·신고·동의 기록을 대상으로 합니다. 삭제 완료를 확인하지 못하면 성공으로 표시하지 않고 다시 확인할 수 있도록 기기 정보를 유지합니다.

## 앱을 지우기 전 확인

앱 삭제만으로 서버 자료가 함께 삭제되지는 않습니다. 앱을 지우기 전 관리 화면에서 삭제 코드를 확인하면 외부 삭제 페이지에서 사용할 수 있습니다. 삭제 코드는 비밀번호처럼 보관하고 이메일·공개 문서에 적지 마세요.

기기의 닉네임·설정은 앱 또는 사이트 데이터 삭제로 지울 수 있습니다. 직접 복사·전송한 메시지와 외부 서비스가 별도 근거로 보관하는 기록은 앱 삭제 대상과 다릅니다.
