# 개인정보 수집·이용 동의

## 수집·이용 목적

주거 문제 분석, 기존 사례 판단, 해결 방법·문의 문구 생성, 사용자별 답변 재사용·한도·보안 관리와 동의 증빙에 사용합니다.

## 처리 항목

문제 글·선택 사진, 임시 사용자 ID·인증 정보, 입력 비교용 식별값, 암호화 답변, 요청 시각·상태·사용량, 항목별 선택·연령 확인·동의 및 철회 시각·고지 버전·해시를 처리합니다. 당시 제공한 본문·체크 문구도 증빙 사본으로 보관합니다.

사진은 선택 사항입니다. 이름·전화번호·얼굴·상세 주소·타인 정보와 불필요한 사진 부가정보를 제외해 주세요.

## 보유·이용 기간

원본 글·사진은 요청 처리 중 사용하며 어쩌집 DB에 별도로 영구 저장하지 않습니다. 암호화한 답변은 7일간 재사용하고 만료 후 정기 정리 대상이 됩니다. 호출 기록 30일, 평가·의견·신고 최대 365일의 보관 정책을 적용합니다.

임시 계정과 연결 자료·동의 이력은 계정 삭제 또는 90일 미활동 정리 절차를 따르며, 사용자 삭제 요청이 먼저 완료되면 연결 자료도 삭제합니다. 외부 제공사의 로그·보안 자료와 백업 사본은 개인정보 처리방침의 별도 기준을 따릅니다.

## 동의 거부·철회와 영향

동의하지 않아도 준비된 기존 사례를 볼 수 있습니다. 글·사진 AI 분석을 이용하려면 해당 정보 처리에 동의해야 합니다. 마이 페이지의 ‘동의 철회·서버 데이터 삭제’에서 철회·삭제를 요청할 수 있습니다. 철회와 과거 자료 전체 삭제는 별개입니다.
