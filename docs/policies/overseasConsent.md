# 개인정보 국외 이전 동의

## 이전 목적·시기·방법

AI 분석과 서버 기능을 위해 필요한 정보를 HTTPS로 전송합니다. 분석을 위한 글·사진은 필요한 선택 동의를 완료하고 분석을 요청한 뒤 전송합니다. 임시 인증·접속·지원 정보는 해당 기능 이용 또는 필요한 운영·보안 처리 과정에서 처리될 수 있습니다.

## Render

이전받는 자: Render Services, Inc. / privacy@render.com

항목·목적: 문제 글·선택 사진, 인증 및 요청 정보를 이용한 분석 서버 호스팅·요청 처리. 기본 분석 서버 위치는 싱가포르이며 계약상 미국 운영 업무가 있을 수 있습니다.

기간: 원본은 요청 처리 중 사용합니다. Hobby 대시보드 로그 조회기간은 7일이며 모든 내부 보안·지원 자료의 보관기간이 같다는 보장은 아닙니다.

## OpenAI

이전받는 자: OpenAI OpCo, LLC / privacy@openai.com

항목·목적: 문제 글·선택 사진·분석 문맥을 미국 지정 API 요청으로 보내 기존 사례 판단과 해결 방법·문의 문구를 생성합니다.

기간: API 응답 저장을 비활성화합니다. 기본 악용 모니터링 기록은 최대 30일과 법령·안전 예외가 적용되며 기능별 임시 보관 조건이 있을 수 있습니다. API 입력·출력의 기본 모델 학습 사용은 하지 않습니다. 이 안내는 별도 무보관 승인을 전제로 하지 않습니다.

## Supabase

이전받는 자: Supabase Pte. Ltd. / privacy@supabase.io

항목·목적: 임시 인증·사용자 ID·암호화 답변·평가·의견·신고·사용량·동의 및 삭제 자료의 저장과 운영. 기본 DB·Auth는 서울이며 운영 로그·텔레메트리는 공식 FAQ상 EU 데이터센터에 처리·저장됩니다. 지원·보안 대응에는 필요한 국외 접근이 있을 수 있습니다.

기간·국가 범위: 앱 DB 자료는 개인정보 처리방침의 7일 재사용·30일 호출·최대 365일 의견/신고 및 계정 삭제·미활동 정리 기준을 따릅니다. 공개 자료는 이 프로젝트의 EU 내 개별 로그 국가와 모든 내부 보안·지원 자료의 정확한 보유기간을 특정하지 않습니다. 기본 API·DB 로그 조회기간 1일과 내부 전체 보유기간은 다릅니다.

## 거부 방법·철회와 효과

각 항목을 선택하지 않거나 동의창을 닫아 거부할 수 있습니다. 마이 페이지의 관리 기능으로 철회하거나 happytanglee@gmail.com으로 요청할 수 있습니다. 거부·철회하면 글·사진 AI 분석을 이용할 수 없지만 준비된 사례는 볼 수 있습니다. 이미 완료된 국외 처리와 별도 근거의 외부 보관 자료가 즉시 모두 삭제되는 것은 아닙니다.
