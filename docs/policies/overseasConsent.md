# 개인정보 국외 이전 동의

## 이전 목적·시기·방법

이전 근거: 개인정보 보호법 제28조의8제1항제1호에 따른 별도 동의를 받아 AI 분석과 관련 서버 기능의 국외 이전을 진행합니다. 해당 선택 동의를 거부하거나 철회하면 AI 분석은 이용할 수 없으며 준비된 사례는 조회할 수 있습니다.

AI 분석과 서버 기능을 위해 필요한 정보를 HTTPS로 전송합니다. 분석을 위한 글·사진은 필요한 선택 동의를 완료하고 분석을 요청한 뒤 전송합니다. 임시 인증·접속·지원 정보는 해당 기능 이용 또는 필요한 운영·보안 처리 과정에서 처리될 수 있습니다.

분석 요청의 기본 경로는 이용자 기기 → 싱가포르 Render 분석 서버 → 미국 지정 OpenAI API입니다. Supabase는 별도로 서울 DB·Auth의 인증·저장 기능을 제공합니다. 분석을 Supabase Edge Function으로 중계하는 구조는 사용하지 않습니다.

## Render

이전받는 자: Render Services, Inc. / privacy@render.com

항목·목적: 문제 글·선택 사진, 사용자 인증·요청 식별 정보와 접속 정보를 이용한 분석 서버 호스팅·요청 처리 및 보안 유지. 기본 분석 서버 위치는 싱가포르이며 계약상 주된 운영 처리 국가는 미국입니다.

시기·방법: 분석 및 관련 서버 기능을 이용할 때 HTTPS로 전송하며, 필요한 운영·보안 처리 과정에서 접근·처리될 수 있습니다.

기간: 원본은 요청 처리 중 사용합니다. Hobby 대시보드 로그는 7일입니다. 계약상 서비스 제공·업무상 필요·법령상 필요한 기간 처리하며 서비스 완료 후 반환·삭제와 법령상 예외 시 처리 제한이 적용됩니다. 모든 내부 보안·지원 자료의 보유기간이 7일이라는 뜻은 아닙니다.

## OpenAI

이전받는 자: OpenAI OpCo, LLC / privacy@openai.com

항목·목적: 문제 글·선택 사진·분석 문맥을 미국 지정 API 요청으로 보내 기존 사례 판단과 해결 방법·문의 문구를 생성합니다.

시기·방법: 이용자가 분석을 요청할 때 분석 서버가 HTTPS로 전송합니다. 앱 사용자 ID·이용자 인증 토큰을 분석 입력에 별도로 첨부하지 않지만, 공급자의 API 사용·보안 관련 정보는 발생할 수 있습니다.

기간: API 응답 저장을 비활성화(store:false)하고 모델 피드백, 평가·파인튜닝 및 API 입력·출력의 선택적 데이터 공유를 비활성화합니다. API 입력·출력을 기본적으로 모델 학습에 사용하지 않습니다. 기본 악용 모니터링 기록은 최대 30일이며 법령 준수 또는 서비스·제3자 보호에 필요한 연장 예외가 적용될 수 있습니다. 이미지 안전 검사에서 잠재적 아동 성착취물로 표시된 자료는 수동 검토를 위해 보관될 수 있습니다. 모델의 프롬프트 캐시 등 기능별 임시 보관 조건도 적용되며 해당 캐시는 최대 24시간 보관될 수 있습니다. 응답 저장 비활성화는 모든 로그·임시 사본의 즉시 삭제나 ZDR(무보관)을 뜻하지 않습니다.

조건부 콘텐츠 검토: 정책 위반으로 표시된 콘텐츠의 표본은 검토를 위해 TaskUs, LLC(필리핀), Accenture International Limited(미국·캐나다·필리핀), Cinder Technologies, Inc.(미국)에서 처리될 수 있습니다. 공식 목록은 검토 플랫폼의 표본을 검토 기간 동안 보관한다고 설명합니다. 모든 분석 요청이 이들에게 전달된다는 뜻은 아닙니다. 미국 지정 API도 모든 시스템 정보·지원 처리를 미국에 한정한다는 보장은 아닙니다.

계약과 처리 역할: 어쩌집은 별도로 체결한 계약이나 무보관 승인을 전제로 하지 않고 OpenAI의 일반 서비스 계약과 DPA를 적용합니다. 이전받는 자는 OpenAI OpCo, LLC이며 고객을 대신하여 분석 입력·출력 등 Customer Data를 처리하는 수탁자 역할을 합니다.

주요 콘텐츠 처리: 미국 지정 API를 사용하며 공식 문서는 해당 요청의 Cloudflare TLS 종료·HTTPS 복호화가 미국 처리 지역 안에서 이루어진다고 설명합니다. API 인프라 하위처리자에는 Microsoft, CoreWeave, Oracle, Google Cloud, AWS, Cerebras 등이 있습니다. 공식 전체 목록의 여러 처리 국가를 미국 지정 요청의 글·사진이 모두 거치는 국가로 해석하지 않습니다.

지원·계열사 처리: 공식 목록은 고객이 지원 과정에서 명시적으로 공유한 자료에 한해 고객지원 업체가 처리한다고 설명합니다. 어쩌집은 해당 지원에 이용자 원문·사진·토큰을 첨부하지 않습니다. 별도로 API 기술·운영 지원 계열사에는 OpenAI OpCo, LLC·OAI International, Inc.(미국), OpenAI Ireland Ltd.(아일랜드), OpenAI UK Ltd.(영국), OpenAI Japan Ltd.(일본)가 공개되어 있습니다. 이는 계열사별 공개 역할·처리 가능 범위이며 모든 요청의 실제 배정을 뜻하지 않습니다. 미국 지역 제어는 시스템 정보 전체를 포함하지 않습니다.

미국 지정 처리: 분석 서버는 https://us.api.openai.com/v1/responses로 요청합니다. Global 지역 프로젝트에서도 공식 문서가 지원하는 요청별 미국 지역 처리를 사용하며, 프로젝트 자체의 지역이 미국이라는 뜻은 아닙니다. 지역 처리는 지원되는 모델·기능의 고객 콘텐츠에 적용되며 계정·사용량 등 시스템 정보 전체와 별도 지원 처리를 미국에 한정하지 않습니다.

## Supabase

이전받는 자: Supabase Pte. Ltd.(싱가포르) / privacy@supabase.io. 미국 Supabase, Inc.는 필요한 지원·운영 업무를 수행할 수 있습니다.

항목·목적: 임시 인증·사용자 ID·암호화 답변·평가·의견·신고·사용량·동의 및 삭제 자료의 저장과 운영. 접속·서비스 메타데이터와 운영·보안 로그가 발생할 수 있습니다. 기본 DB·Auth는 서울이며 운영 로그·텔레메트리는 공식 FAQ상 EU 데이터센터에 처리·저장됩니다. 지원·보안 대응에는 필요한 국외 접근이 있을 수 있습니다.

시기·방법: 인증·저장 등 해당 기능을 이용할 때 HTTPS로 전송하고 필요한 운영·보안 처리 시 국외에서 원격 접근할 수 있습니다. 서울 DB·Auth 저장과 국외 로그·접근을 구분하며 사진 원본을 Supabase Storage에 업로드하지 않습니다.

기간·국가 범위: 앱 DB 자료는 개인정보 처리방침의 7일 재사용·30일 호출·최대 365일 의견/신고 및 계정 삭제·미활동 정리 기준을 따릅니다. 계약은 계약 기간 중 보유하되 서비스 기능을 통한 조기 삭제를 반영하고 계약 만료 후 30일 반환 기간 종료 시 대상 사본 삭제를 정합니다. 개별 이용자의 모든 로그를 30일 보관한다는 뜻은 아닙니다. EU 내 개별 로그 국가·미국 외 지원 국가와 내부 기록별 세부 보유기간은 공개 자료로 특정되지 않았습니다. Free 로그 조회기간 1일과 전체 보유기간은 다릅니다.

공개된 위탁 범위: 하위처리자 목록은 호스팅·모니터링·보안·관리자 지원 등의 역할을 구분합니다. 목록의 법인 소재국을 서울 DB나 EU 로그의 실제 처리 국가로 대신 적지 않으며, 사용하지 않는 Storage 사진 업로드·마켓플레이스·운영자 지원 자료를 모든 앱 이용자의 상시 처리 경로로 보지 않습니다. 공급자의 필요한 운영·보안 처리는 별도로 남습니다.

계약과 추가 공유: Supabase DPA는 이용약관에 포함되어 Free 조직에도 자동 적용되며 별도 서명이 필요하지 않습니다. 어쩌집 조직의 Supabase Assistant 데이터 공유는 비활성화되어 있습니다. 이 설정은 앱의 OpenAI 분석이나 Supabase의 서비스 운영·보안 처리를 중단하는 설정은 아닙니다.

## 지원 문의와 사진의 최소화

운영팀은 공급자 지원 문의나 공급자 AI 도우미에 이용자 원문·사진·인증 토큰을 첨부하지 않습니다. 이 방침이 공급자의 필요한 보안 사고 대응이나 API 악용 검토까지 차단한다는 뜻은 아닙니다.

사진은 전송 전에 원본 파일명과 EXIF·GPS 등 원본 메타데이터를 제거하며 처리 실패 시 원본을 대신 전송하지 않습니다. 글 속 개인정보나 사진에 보이는 얼굴·주소·문서 내용까지 자동 제거되는 것은 아니므로 분석에 불필요한 개인정보는 제외해 주세요.
