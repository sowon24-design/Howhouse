# AI 활용 정보

## AI는 어디에 사용되나요?

카테고리와 인기 문제에서는 준비된 기존 사례를 보여 줍니다. 직접 문제를 입력하면 AI가 적합한 기존 사례를 먼저 찾고, 없으며 정보가 충분할 때만 새 해결 방법과 문의 문장 초안을 생성합니다. 직접 입력했다는 이유만으로 항상 새 답변을 만드는 것은 아닙니다.

## 어떤 정보가 전송되나요?

분석을 요청할 때 입력한 글과 직접 선택한 사진이 분석 서버를 거쳐 OpenAI API로 전송됩니다. 원본 글·사진은 분석 서버에 영구 저장하지 않도록 구성되어 있습니다. 외부 제공사의 처리·보관은 별도 기준이 적용됩니다. 이름·연락처·얼굴·상세 주소를 제외해 주세요.

## 기존 사례와 생성 결과는 달라요

기존 사례는 준비된 제목·준비물·단계·영상 등을 표시합니다. 생성 결과는 AI가 작성한 내용이며, 준비되지 않은 소요 시간·배상 책임·영상·실제 사례 사진을 임의로 채우지 않습니다. 현재 기존 사례의 대표 이미지는 AI로 만든 예시이며 실제 제보 사진이 아닙니다.

## 답변은 참고 정보예요

AI는 잘못된 원인이나 안전하지 않은 방법을 제시할 수 있습니다. 현장 진단·법률 자문·긴급 대응을 대신하지 않으며, 배상 책임과 비용 부담을 확정하지 않습니다. 위험이 의심되면 작업을 멈추고 안전한 곳에서 관리 주체·전문가에게 확인해 주세요.

## 메시지는 직접 확인하고 보내세요

문의 메시지는 초안입니다. 받는 대상과 내용을 확인하고 필요한 부분을 수정해 주세요. 문장 선택·편집·복사에는 추가 AI 분석을 요청하지 않습니다. 복사는 클립보드로 옮기는 기능이며, 앱이 문자 앱을 실행하거나 메시지를 자동 전송하지 않습니다.

## 저장과 삭제는 구분해 주세요

같은 입력의 검증된 답변은 사용자별로 암호화하여 재사용할 수 있습니다. 현재 재사용 유효기간은 7일이며, 만료 즉시 모든 DB·백업에서 삭제된다는 뜻은 아닙니다. 기기 데이터나 앱을 지워도 서버의 인증·답변·평가 기록이 함께 지워지지는 않습니다. 구체적인 항목과 삭제 요청은 개인정보 처리방침을 확인해 주세요.

## 문제 있는 결과는 알려주세요

결과 화면의 AI 답변 신고에서 위험하거나 부적절한 답변을 신고할 수 있습니다. 신고 사유·직접 작성 의견과 화면에 표시된 답변 일부를 암호화해 보관하고, 유소원 담당자가 운영자 화면에서 검토합니다. 신고에는 원본 문제 글·사진을 추가로 저장하지 않습니다. 저장에 실패하면 내용을 유지하므로 다시 시도해 주세요. 접수된 신고는 운영자가 확인하고 필요한 사례·생성 지침 개선에 활용합니다.
