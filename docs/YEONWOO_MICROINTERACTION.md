# 연우 개인 과제 — 마이크로 인터랙션

- 브랜치: yeonwoo-microinteraction-assignment
- 기준: 원격 main 0a337ca54596259487e72103ca21e10e95e3ff37 (2026-11-21 확인)
- 실제 서비스 컴포넌트에 적용. 메인 병합 및 출시 배포는 수행하지 않음.
- 사용자가 선정한 두 영역과 효과를 구현했으며, 아래 세부 시간·거리 수치는 Codex의 구현 초안이다. 개인 보고서에는 직접 실습하며 유지·수정한 판단을 덧붙인다.

## 1. A01 → B01

| 순서 | 트리거 / 상태 | 피드백 |
| --- | --- | --- |
| 1 | 카테고리 또는 B01 목록 클릭 | 색을 hover로 전환하며 180ms 동안 1 → .97 → 1 크기 변화. 연속 클릭 실행은 한 번만 허용 |
| 2 | 홈에서 카테고리 이동 | 기존 화면 110ms 페이드아웃, 새 화면은 70ms 후 180ms 페이드인. 앱의 surface 배경을 잠깐 노출 |
| 3 | B01 진입 | 목록 li가 70ms 뒤부터 항목당 38ms 간격, 각 260ms 동안 투명도 0 → 1 및 Y 10px → 0 |
| 4 | 화장실 B01 표시 | Figma 1378:10745 / 1378:10757 원본 두 레이어의 2.4초 반복 모션 |

색상 근거: Figma Color/neutral Light #E9EEF7, Composition button/secondary/hover #D4DDE9. 다른 전역 컴포넌트의 상태 토큰은 바꾸지 않고 과제 적용 요소에만 사용한다. 제공된 모션은 화장실 카테고리에만 있으므로 다른 카테고리 일러스트는 유지한다.

## 2. B02-1 해결완료 / B02-3 의견완료

| 순서 | 트리거 / 상태 | 피드백 |
| --- | --- | --- |
| 1 | 해결완료 시트 열기 또는 의견완료로 전환 | 420ms 동안 아래에서 제자리까지 단방향으로 부드럽게 등장. 오버슈트·반동 없음 |
| 2 | 시트 뒤 배경 | 240ms 딤 페이드인 |
| 3 | 완료 일러스트 표시 | 원본 몸체·왼손·오른손·체크파일을 조합. 팔과 파일의 3.2초 반복 모션은 Figma 키프레임·피벗·easing 사용 |
| 4 | 시트 버튼 클릭 | 해당 기존 Button variant의 hover 색 + 180ms 축소·복원 후 콜백 실행 |
| 5 | 시트 닫기 | 220ms 하강. 기존 포커스 복원·스크롤 잠금·Escape·손잡이 드래그를 유지 |

현재 main의 의견은 화면 내 상태로만 유지되므로 완료 문구도 그 동작을 보존한다. 서버 접수 성공을 표시하거나 새 전송 기능을 추가하지 않는다.

## 3. Figma / Codex 활용 기록

- A01 1378:10759, B01 1378:10116, B02-1 1378:10160, B02-3 1378:10259의 디자인과 실제 스크린샷 조회.
- get_motion_context로 B01의 두 모션과 완료 일러스트의 세 모션을 각각 분해하여 확인.
- 공통 색상 변수의 alias를 해석해 Color/neutral과 Composition hover 값을 확인.
- 임시 Figma URL은 실행 시 참조하지 않고 원본 파츠를 로컬 에셋으로 저장.
- 사용자 지시: 별도 연우 과제용 브랜치, 두 요청을 각각 적용·저장, 두 결과를 여기서 확인 가능하게 제작.
- 구현 지시 요약: 홈→카테고리 디졸브, 목록 순차 등장, 원본 일러스트 모션, hover 색과 축소·복원, 완료 시트의 작은 정착 모션.

## 4. 실행 / 검증

의존성 설치: npm ci

실행: npm run dev -- --port 5187

일반 앱: http://127.0.0.1:5187/

두 시연: http://127.0.0.1:5187/assignment-preview.html

타입 검사: npm run typecheck

과제용 빌드: npm run build -- --mode catalog-preview

확인: 실제 앱 홈→화장실→사례, 해결완료, 의견 선택→완료, 버튼·Escape 닫기, 시트 재열기, 360px 터치와 동작 줄이기. 동작 줄이기에서는 이동·축소·반복 모션 없이 즉시 전환한다. View Transition API 미지원 환경은 즉시 화면 이동하며 B01 목록 등 다른 피드백은 동작한다.

개인이 추가할 기록: 직접 바꾼 수치와 이유, 실습 후 느낀 차이, 팀이 최종적으로 서비스에 적용하기로 한 결정. 아직 팀 최종 결정은 내려지지 않았다.
