# 검토한 UI 복원 및 보존 범위

이 문서의 복원 시점 기록 이후 B03 메시지 앱 연결과 관련 정책 본문을 수정했다. 최종 변경과 검증은 `B03_MESSAGE_COMPOSER_REVIEW.md` 및 아래 재실행 로딩 기록을 함께 확인한다. 아래의 정책·Android·외부 전송 무변경 문장은 초기 UI 복원 단계에 한정한다.

- 기반: `origin/main`의 `0a337ca` (PR #68 유튜브 반영 포함).
- UI 기준: `feature/app-screens`의 기존 사용자 검토본과 대화에서 확정한 동작.
- 작업 브랜치: `codex/restore-reviewed-ui`.

## 복원

- A01 돋보기 배너와 문구, A08 추천 검색·입력, A09 결과/결과 없음 화면 연결.
- 추천어 선택 즉시 결과 이동, A09에서 A08로 돌아오면 입력 초기화, 사례에서 검색 결과로 돌아올 때 검색어 유지.
- D01 프로필·정보 메뉴, 닉네임 수정, 기존 공개 Notion 링크, 문의 화면 연결. 일반 사용자 화면의 초기화 버튼 제거.
- E01~E04 검토한 문구·CTA·뒤로/닫기 구성. 온보딩 약관 시트만 단락부터 시작하고 시행일은 마지막에 표시.
- F01 최소 1초 및 폰트 준비 후 이동.
- B01 사례 목록의 기존 해요체 매핑, 다른 사례 찾아보기 제거.
- B02 준비물 정적 태그·on-surface 글자색, 카드 세로 패딩 16px, 평가 대신 안내 캡션. B03 편집 캡션 및 B02 복귀 시 스크롤 보존.
- 앱 프레임의 반응형 너비 및 키보드 축소 화면의 기존 20px CTA 간격.

## 최신 main 보존

- `src/youtube/` 전체, `VideoPreview.tsx`, B02 영상 JSX 및 영상 CSS 규칙은 main과 동일하다. API, 썸네일, 딤, 공식 출처 아이콘, 요청 제한·취소·해제 동작을 변경하지 않았다.
- `src/catalog/policy.ts`, `docs/catalog-policies/` 원문과 공개 HTML, 약관 버전 및 재확인 절차를 유지했다. 새 프로필에도 현재 약관 버전을 저장한다. Google·YouTube 정책 링크의 클릭 기능을 유지했다.
- Android 설정·권한·아이콘·서명·버전, 출시 승인값, Vite CSP 및 유튜브 출시 검사에 변경이 없다.
- 사례 원문·검색 사전·검색 알고리즘에 변경이 없다. UI에서 이미 존재하는 검색 및 목록 문구 매핑을 다시 사용한다.

## 확인 결과

- 타입 검사, catalog-preview 빌드, 공통 기반 자산 검사 통과.
- 사례 검색·콘텐츠 검사 76개, 유튜브 요청·동의·출시 조건 검사 16개 통과.
- `policies:check`: 앱 원문과 6개 정책 문서 동기화 확인. Notion 게시 내용은 이 검사에 포함되지 않는다.
- 브라우저 412×910: 온보딩 문구, 약관 시트의 유튜브 안내·정책 링크·하단 시행일, 닉네임 완료, 홈, 추천어 즉시 검색, 검색 결과 뒤로 입력 초기화, 검색 실패 문구, 마이 메뉴, 카테고리, B02/B03 이동 확인.
- ‘에어컨 물 떨어짐’ 검색에서 해당 누수 사례가 첫 번째로 표시됨을 확인했다.
- B03에서 B02 복귀 시 스크롤 위치 769.33px 보존을 확인했다.
- 800×1280에서 B02와 검색 화면의 앱 프레임/문서 너비가 800px임을 확인했다.

## 별도 확인 범위

- 이번 로컬 미리보기는 유튜브 API 키를 설정하지 않았다. 실제 원격 썸네일 성공 응답은 재검증하지 않았으며 유튜브 관련 코드는 변경 없이 보존했다.
- Android 재설치·실제 키보드·하드웨어 뒤로·외부 앱 전환 및 Notion 공개 본문 최신 일치는 이번 브라우저 검사에 포함되지 않는다.
- 개인정보의 새 수집 항목·외부 전송 경로·SDK·권한을 추가하지 않았다. 본 기록은 출시 승인이나 정책 적합성 인증이 아니다.

## 앱 재실행 로딩 (2026-11-22)
- 앱 아이콘으로 기존 Android task를 다시 열 때도 기존 F01 LaunchScreen을 최소 1초 표시한다. 최초 WebView 실행의 폰트 준비 대기는 유지한다. 사용자 요청의 F02는 로딩 화면을 지칭하며, 코드의 F02 오프라인 화면은 변경하지 않았다.
- ACTION_MAIN + CATEGORY_LAUNCHER의 onNewIntent만 처리한다. 문자 앱·YouTube·브라우저에서 단순 복귀할 때는 로딩을 다시 띄우지 않는다.
- 타입 검사, catalog-preview 웹 빌드, Android debug APK 빌드 통과. 기기에서 완전 종료 후 시작 및 홈 아이콘 재진입의 화면 확인은 아직 하지 않았다.
- 외부 서비스·권한·정보 처리·YouTube 동작·정책 본문 변경 없음. 기존 정책 버전과 승인 검토 상태를 유지한다.
