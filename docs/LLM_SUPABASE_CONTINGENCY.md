# Supabase 유지와 미응답 시 대안 검토

작성일: 2026-11-10. 현재 결정은 Supabase 유지다. 교체·기능 제거·사용자 데이터 이전·유료 가입은 실행하지 않았다.

## 미확정 정보를 다루는 원칙

- 공식 문서와 실제 계정에서 확인한 사실, 공급자 답변, 미확정 항목을 분리한다. DB가 서울인 것과 모든 로그·지원이 국내에서 처리되는 것은 다르다.
- 확인된 사실: Supabase DPA는 2026-08-01부터 약관에 포함된다는 답변을 받았다. Free API·DB 로그 기본 보관은 1일, 프로젝트 DB·Auth는 서울이며 자동 일일 프로젝트 백업은 Free에 포함되지 않는다.
- 미확정: EU 내 실제 운영 로그 국가, 별도 내부 보안·지원 기록 보관기간과 삭제 기준, 해외 지원 전체 처리 국가·범위, 개별 사용자 삭제 후 잔존 기록의 기준. 팀의 수동 DB 내보내기 존재 여부도 별도로 확인해야 한다.
- 공급자의 DPA 자동 적용 답변은 로그 국가·기간에 대한 답변으로 간주하지 않는다. 미응답을 무보관·국외 이전 없음으로 바꾸지 않는다. ‘EU 등’, ‘전 세계’, ‘확인 중’ 문구만으로 필요한 국가·보유기간 고지를 충족했다고 승인하지 않는다.
- 앱 자체의 7/30/90/365일 정책은 해당 앱 데이터에 적용하며 공급자 내부 기록 전체의 기간으로 확대하지 않는다. 무보관 승인 이력이 없는 OpenAI의 store:false도 전체 무보관으로 설명하지 않는다.
- 국외 이전에는 법령상 여러 근거가 있으므로 모든 경우에 별도 동의만 유일한 근거라고 단정하지 않는다. 다만 현재 앱은 별도 동의 경로로 준비됐으며, 다른 근거로 전환해도 필요한 사실 확인을 생략할 수 있다고 가정하지 않는다. 법적 해석이 필요한 공백은 개인정보 전문가 검토 대상으로 분리한다.

## 교체안의 선택 조건

새 업체는 이름만 고르지 않고 다음 자료를 먼저 확인한다: 계약 법인과 개인정보 연락처, 선택한 DB/Auth 지역, 프로젝트 로그 저장 국가·보관기간, 내부 보안·지원 기록과 해외 접근, 백업·삭제, 재위탁 조건, 월 총비용. 클라우드 회원의 개인정보 방침과 우리 앱 이용자의 처리 계약을 혼동하지 않는다. AWS는 지원 처리 법인·국가 목록이 구체적이지만 전체 무보관을 보장하는 뜻은 아니다. 국내 업체도 미확정 조건이 자동 해소되는 것은 아니다.

기존 서비스는 검증 완료까지 보존한다. 테스트 환경에 새 구조를 만들고 권한·재시도·순서 역전·본인 삭제·타인 접근 거부·사용량 제한을 검증한 뒤 전환한다. 서버 키는 앱에 넣지 않는다. Render와 OpenAI를 계속 쓰면 그 업체의 국외 처리 고지는 계속 필요하다.

## 기능 제거안을 선택할 때의 실제 범위

‘분석 버튼 숨김’만으로 처리 중단을 확인하지 않는다. App 초기화의 임시 인증, 세션·health 요청, 피드백 저장, 동의·삭제 코드 요청, 외부 썸네일 로딩 등 자동 요청을 모두 확인한다. 정적 사례에 외부 영상·구매 링크를 남기면 클릭 시 외부 이동임을 안내하고 실제 요청 시점을 검토한다. 불필요한 외부 이미지 자동 로딩은 제거·대체한다. 앱 안에 비활성 코드나 서버 주소가 남아 있는 것과 실제 외부 요청이 없는 것은 구분해 네트워크로 검사한다.

AI를 남기면 앱 내 부적절한 AI 결과 신고와 실제 검토 경로도 남겨야 한다. 신고 저장을 없애면서 신고 기능이 동작한다고 표시하지 않는다. 공급자 데이터 경로를 줄이더라도 Play의 데이터 보안·개인정보 처리방침·권한 신고는 최종 동작에 맞게 다시 작성한다.

제거안은 사용자 결정 전 실행하지 않는다. Supabase를 사용하지 않는 새 앱을 만들더라도 기존 서버의 사용자 데이터와 삭제 의무는 자동 소멸하지 않으며, 기존 프로젝트를 임의 삭제하지 않는다.

## 권장 진행

지금은 Supabase를 유지하고, 비공개 테스트 준비·동의 연결·제출 자료를 먼저 완성한다. 공급자 미확정 항목이 해소되지 않으면 실제 API 이용자 모집/배포를 무조건 진행하지 않고, 교체안 또는 기능 축소안을 사용자와 선택한다. 테스트 트랙도 개인정보 의무의 면제 수단으로 취급하지 않는다. 프로덕션 액세스 요건 때문에 추가 테스트 기간이 필요하므로, 현재 일정은 ‘즉시 공개 출시’가 아니라 안전하게 검증한 비공개 테스트 후보 준비를 기준으로 관리한다.
