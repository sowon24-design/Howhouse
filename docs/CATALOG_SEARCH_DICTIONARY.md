# 사례 검색 사전 반영

2026-11-10 / `codex/ai-without-supabase`

원본: https://docs.google.com/spreadsheets/d/1wQrHioHd9a25F-jTumVqPFj8WcTC1-YPwrBW6QivAlI/edit

시트 `사례별 검색어`, `검색 정렬 기준`을 실제 읽었다. 자료는 신규 해결책이 아니라 기존 활성 사례 53개의 검색 사전이다. 원본 사례 ID·증상은 CSV와 전부 대조하며, 해결 단계·문의 문장·원본 시트는 변경하지 않는다.

- 검색 사전: `src/catalog/search-dictionary.json`. 대상·장소와 증상만 분리해 저장. 입력 예시·혼동 주의는 검색어에 포함하지 않음.
- 기기 내 관련도 정렬: 대상 3, 증상 5, 동시 일치 4, 구체 구문 2. 각 그룹 상한 적용. 원문 제목/증상 완전 일치 우선, 동점은 구체 구문 및 고정 ID 순. 확률로 표시하지 않음.
- 알려진 활용형과 띄어쓰기 변형 처리. 세탁기·냉장고·변기 등 명시한 대상과 다른 후보 제외. 일부 명백한 부정 표현 제외.
- 없는 사례 생성 없음. 검색어 저장·전송·유료 API 없음. 검색은 진단으로 설명하지 않음.
- 모든 자연어의 부정·동의어·오타를 이해하는 기능은 아님. 복합 문장·등록하지 않은 표현은 추가 사전 보완 대상. 자동 오타 보정·강제 5개 상한·AI 유사도는 도입하지 않음.
- 위험 표현은 검색 화면에 직접 수리 금지와 도움 요청 안내를 함께 표시하되 위험 탐지의 완전성을 보장하지 않음.

검증: 대표 검색·부정문·없는 사례·반복 단어 등 검사 5개, 53개 ID/원문 대조. 실기기 테스트는 사용자 요청대로 후속 진행.

새 해결 사례를 추가하려면 증상뿐 아니라 준비물·단계·문의 문장 등 원본 사례 데이터가 필요하다. 이번 자료만으로 해결책을 임의 작성하지 않았다. 원본 시트는 앱에 자동 동기화되지 않는다.
