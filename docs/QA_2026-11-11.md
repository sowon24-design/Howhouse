## 확인된 수정 대상

### 1. B03에서 돌아오면 B02 스크롤 위치가 초기화됨 — 보통

- 재현: G66 B02 아래로 이동 → 해결 완료 시트 → 문의 메시지 작성 → B03 뒤로.
- 실제: 진입 전 B02 스크롤 위치 약 419px가 복귀 후 0px로 변경됨.
- 기대: B02↔B03에서는 기존 읽던 위치 유지. B01 등에서 B02를 새로 열 때는 초기화.
- 관련 코드: `src/catalog/CatalogApp.tsx`의 `[hash, contact, editing]` 변경 시 `scrollTo({top:0})` 처리.
- 권장: 문의 화면 진입 직전 B02 위치를 보관하고 돌아올 때 복원하도록 분리.

### 2. 삭제 요청한 설정 초기화가 이전 내부 주소에 남음 — 낮음

- 재현: `/#my/data` 직접 진입.
- 실제: ‘이 기기의 설정 초기화’ 버튼과 ‘이전 AI 버전’ 안내가 표시됨. 초기화 버튼 자체는 누르지 않음.
- 일반 D01에서는 외부 Notion으로 연결하므로 기본 메뉴에서 바로 노출되지는 않음.
- 관련 코드: `src/catalog/CatalogMy.tsx`, `CatalogMyDetail`의 `page === 'data'` 분기.
- 권장: 남은 버튼·안내 제거 또는 사용하지 않는 내부 경로 정리.

### 3. 검색 결과 제목의 조사가 검색어에 맞지 않음 — 낮음

- 재현: ‘에어컨 물 떨어짐’ 검색.
- 실제: ‘에어컨 물 떨어짐’와 비슷한 문제…로 표시됨.
- 관련 코드: `src/catalog/CatalogSearch.tsx`의 고정 조사 ‘와’.
- 권장: 조사 처리 또는 ‘검색한 내용과 비슷한 문제…’처럼 조사 선택이 필요 없는 문장 사용.

## 후속 수정·재확인

사용자 요청에 따라 위 3건을 수정했다.
- B02→B03 진입 전 위치를 보관하고 같은 사례로 돌아올 때 복원. 웹에서 진입 전·복귀 후 모두 419.33px로 확인했다. 다른 경로 진입은 기존처럼 맨 위에서 시작한다.
- 이전 내부 데이터 안내 화면의 초기화 버튼·이전 AI 버전 설명 및 onReset 연결 제거. 개발용 테스트 초기화는 유지했다. /#my/data에서 제거 확인.
- 검색어 받침에 따라 와/과 선택. 한글·숫자·끝 문장부호 등 7개 입력 검사와 타입 검사 통과. 웹에서 ‘에어컨 물 떨어짐’과 표시 확인. 발음을 확정할 수 없는 영문 등은 와(과) 병기.
- 변경 파일: src/catalog/CatalogApp.tsx, CatalogMy.tsx, CatalogSearch.tsx, search-particle.ts. 실제 Android 재설치·검증 및 commit·push는 하지 않았다.

## Android 재설치 및 캡처 설정

- 후속 수정 후 회귀 검사 99개와 catalog-preview 빌드 재통과. Capacitor 동기화에서 app 플러그인 1개만 확인.
- 동기화 후 assembleDebug 성공, Pixel_10(emulator-5554)에 install -r 성공 및 MainActivity 실행 요청 성공. 기존 앱 데이터 삭제 없음.
- 캡처용 Pixel 에뮬레이터 해상도 2160×3840, 밀도 840, 배터리 100% 확인. 원래 물리 해상도 1080×2424, 밀도 420. 원복: adb -s emulator-5554 shell wm size reset / shell wm density reset.
- 실제 폰과 두 태블릿 AVD 설정은 변경하지 않았다. 최종 업로드 이미지 전체를 9:16으로 제작하며, 이 설정만으로 모든 실기기 인터랙션 재검증이 완료된 것은 아니다.
- 개발용 catalog-preview APK이며 출시 서명 AAB가 아니다. 출시 승인 설정·정책 본문·외부 서비스 처리 범위는 변경하지 않았다. 개발용 안내 도구가 포함되므로 제출 캡처 시 제외해야 한다.
