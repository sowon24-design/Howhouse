# 첫 Play 업로드 준비

사용자 확인: 아직 AAB/APK 업로드 없음. 첫 제출 값은 `com.howhouse.app` / versionCode 1 / versionName 1.0. 기준 파일은 `src/catalog/app-release.json`. QA APK의 `.catalogqa` ID는 제출하지 않는다.

ko-KR 폴더에는 소개문·첫 출시 설명 입력용 텍스트를 준비했다. 실제 Console에 저장·게시하지 않았으며 최종 앱과 문서를 대조한 뒤 사용한다. 이메일 처리 조건과 공개 정책이 미완료인 상태에서 ‘개인정보를 전혀 수집하지 않는다’고 홍보하지 않는다.

순서: 새 개인정보/약관 공개 URL 및 시행일 확정 → 앱 문서 연결 → 실기기 검증 → 스토어 이미지/설문 정리 → 사용자 기기에서 업로드 키로 서명 AAB 생성 → 비공개 테스트 트랙에 첫 업로드 → 계정에 요구되는 테스트 및 프로덕션 액세스 → 공개 심사 제출.

진행 중인 미완료 항목은 `node scripts/catalog-preflight.mjs`로 확인한다. 이 명령은 실패 항목을 자동 수정하거나 승인하지 않는다.

아직 필요한 자산: 최종 512×512 아이콘, 1024×500 대표 이미지, 검증한 실제 앱 스크린샷. 기존 앱 리소스를 제출용 고해상도 자산이라고 임의로 간주하지 않는다.
