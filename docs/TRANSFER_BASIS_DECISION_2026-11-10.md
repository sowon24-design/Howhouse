# 국외 이전 고지·근거 판단과 최소화 결정

2026-11-10 / 로컬 검토 결정. Supabase Free와 AI·사진 분석 유지. main·운영·계정 설정 변경 없음. 업체 회신을 기다리는 절차는 두지 않는다.

## 결론

공개 자료로 확정 가능한 사실과 앱의 근거 선택은 아래처럼 정리한다. 그러나 공개 자료에 없는 실제 지원 국가·개별 기록 삭제 조건을 만들어 채울 수는 없다. 따라서 **공개자료 검토 완료와 전체 고지 적합성 승인 완료는 구별한다. 현재 전체 적합성은 미확인**이다. 이는 확인된 위법 판정도, 유료 이전 필요 판정도 아니다. 승인 플래그는 false로 유지한다.

## 고지 대상에서 구별·제외할 수 있는 것

1. **운영자 본인의 계정·결제 정보**: 앱 이용자 데이터와 별도. 업체의 마케팅·결제용 처리업체를 앱 이용자의 분석 수령자로 일괄 나열하지 않는다. 이용자 정보를 고객지원에 넣으면 그 첨부는 다시 별도 검토한다.
2. **사용하지 않는 제품의 처리**: 코드상 Supabase Storage 사진 업로드·CDN, OpenAI Files·Assistants·대화 저장을 사용하지 않는다. 해당 기능만의 처리 경로를 실제 사용하는 것으로 고지할 필요는 없다. 업체의 공통 인프라 사용까지 배제됐다는 뜻은 아니다.
3. **자발적 고객지원 첨부**: 이용자 원문·사진·토큰을 지원 티켓·제공사 AI 도우미에 넣지 않는 운영 원칙으로 그 첨부 처리를 피한다. Supabase의 보안 사건 대응 접근, OpenAI의 필수 악용 검토와는 구별한다.

## 공개 자료만으로 최종 확정하지 못한 최소 잔여 목록

1. Supabase EU 로그의 실제 개별 국가·하위수령자 연결, 미국 외 지원 접근 국가.
2. Render의 기타 운영 처리국·하위처리자 중 이 서비스에 적용되는 경로, OpenAI의 시스템 정보·계열사 지원에 적용되는 구체 경로. 공개 가능성 목록과 실제 적용 경로는 다르다.
3. 업체 내부 접속·보안 기록의 세부 종료·삭제 조건과, 공개된 조건형 기간이 국내 고지 요건에 충분한지. 고정 일수가 없다는 사실 자체만으로 자동 위법이라고 판정하지 않는다.
4. 조건부 재수령자 등 공개 자료에서 확보되지 않은 개별 연락처와, 해당 재이전에 대해 어느 수준까지 이용자 고지가 필요한지의 적용 판단. 주계약 업체 연락처를 다른 업체 연락처로 대신 기재하지 않는다.

이 네 항목은 앱에서 선택적으로 붙인 기능만 제거하여 전부 없앨 수 있다고 확인되지 않았다. 특히 필수 보안 로그·사고 대응·악용 검토는 관련 호스팅·인증·API를 계속 쓰면 남을 수 있다. 사용자 조건(현 구조·무료·AI 유지) 아래에서 잔여를 모두 없애는 무료 설정이나 코드 변경은 공개 자료로 확인되지 않았다. 따라서 '공개 자료로 충분히 해결됨'이나 '약관만 바꾸면 출시 가능'으로 승인하지 않는다.

공개자료 검토를 같은 검색으로 반복하기보다, 남은 법 적용 판단이 필요하다면 위 국가·기간·재이전 네 항목만 묶어 개인정보위 법령해석지원센터(공식 안내 02-2100-3043)에 확인할 수 있다. 이는 업체 답변 대기가 아니며, 회신 날짜·승인 결론을 보장하지 않는다. 질의 제출·전화는 이번 작업에서 하지 않았다.

## 산출물·출시 판정

앱의 국외 이전 고지에 별도 동의 근거 조문을 명시하고 기존 v6 로컬 초안의 본문·노션 전달 파일을 동기화했다. v6는 미공개·미승인 초안이므로 이번 편집에서 버전을 추가로 올리지 않고 해시를 재생성했다. 실제 Notion은 미수정. 승인 상태는 false 유지.
