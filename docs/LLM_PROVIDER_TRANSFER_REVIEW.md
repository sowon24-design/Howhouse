# 제공업체별 국외 처리 확인 기록

2026-11-06 기준. 이 문서는 설정·공식 정책 대조 기록이며 미확정 상태의 앱 동의를 대신하는 공개 정책이 아니다.

## 실제 서비스 흐름

앱에서 선택한 글·사진 → Render 분석 서버(싱가포르) → OpenAI API. Supabase 프로젝트 DB는 서울(`ap-northeast-2`)이며 임시 인증과 사용자별 암호화한 답변·평가·의견·신고, 동의·삭제 처리 기록에 사용한다. DB가 국내에 있다는 이유로 모든 업체의 국외 처리가 없어지는 것은 아니다. 앱에는 공개 URL과 publishable 키만 포함하고, 비밀 키는 서버에만 둔다.

| 업체 | 목적·항목 | 확인된 위치·조건 | 공개 전 추가 확정 사항 |
|---|---|---|---|
| OpenAI | 문제 글·선택한 사진·사례 요약으로 기존 사례 적합성 판단 및 필요한 경우 해결 방법·문의 초안 생성 | 시험 서버는 미국 지정 주소 `us.api.openai.com`을 사용하며 2026-11-06 고정 문장 1회 응답 성공을 확인했다. 지역 실패 시 Global로 자동 우회하지 않는다. | Render | 원본 글·사진을 요청 처리 중 일시 처리, 서버 접속·보안·운영 기록 | 실제 API 서비스는 Singapore, Free. 애플리케이션은 원본 문제·사진을 DB에 영구 저장하지 않는다. 고정 진단 코드만 출력하며 사용자 본문·키를 로그에 쓰지 않는다. | Render의 운영·보안 로그 항목, 재위탁·지원 처리 범위, 해당 계정 플랜의 보관 조건 대조. 서버 지역만으로 모든 지원 처리가 싱가포르에 한정된다고 단정하지 않는다. |

선택한 사진 파일에는 촬영 위치 등 부가정보가 포함될 수 있다. 현재 코드의 사진 처리 검사는 형식·크기·개수와 읽기 실패를 확인하며 모든 메타데이터 제거를 보장하지 않는다. 고지에서 이를 누락하거나 위치를 수집하지 않는다고 무조건 표시하지 않는다.

## 앱 동의 방식

- 만 14세 이상임을 확인하며 생년월일은 수집하지 않는다.
- 초기 화면의 기본 서비스 안내와, 분석 직전 글·사진 처리 및 국외 이전 안내를 구분한다.
- 국외 이전의 별도 동의를 근거로 삼을 경우 일반 약관 전체 동의에 묶어 대신하지 않는다. 처리와 국외 이전의 체크 항목·서버 영수증을 구분해 검토한다.
- 거부하면 분석 요청·사진 업로드를 보내지 않으며 기존 카테고리 사례 조회는 유지한다.
- 마이 페이지에서 철회·서버 데이터 삭제를 제공한다. 삭제가 실패하면 성공으로 표시하거나 기기 정보를 먼저 지우지 않는다.
- 적용 근거에 맞게 받는 자 및 연락처, 이전 항목·국가, 시기·방법, 목적·보관, 거부 방법과 효과를 구체적으로 공개한다. 모든 이전이 반드시 동의 한 가지만을 근거로 해야 한다고 단정하지 않는다.

## 제공업체에 확인할 내용

현재 이용 중인 API·호스팅·인증 서비스에 대해 대한민국 이용자의 글·사진 또는 사용자 ID·접속 기록이 처리되는 국가, 수령 법인과 개인정보 문의처, 처리 목적과 항목, 기본·예외 보관 및 삭제 기간, 지원·로그·백업·재위탁 범위를 확인한다. 개인의 사진·문제 원문·키를 확인 요청에 첨부하지 않는다. 이 저장소의 문서 작성을 이유로 제공업체에 메시지를 자동 발송하지 않는다.

## 사례 영상의 외부 미리보기

B02의 기존 영상 썸네일은 `i.ytimg.com`에서 불러온다. 영상 재생을 누르지 않아도 썸네일 요청 시 IP·브라우저 정보가 Google 측에 전송될 수 있다. 원본 문제 글·사진을 이 요청에 첨부하지 않으며 참조 주소 전송은 no-referrer로 줄인다. 이 흐름도 공개 고지·Play 데이터 보안 검토에 포함한다. 쿠팡 검색 및 영상 재생은 사용자가 외부 링크를 선택하는 동작과 구분한다.
