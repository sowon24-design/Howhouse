# 어쩌집 접근성 적용 가이드

## 1. 적용 대상과 수준
- 기준 브랜치: feature/app-screens. main의 롤백 화면은 이번 과제 기준에서 제외한다.
- 목표 수준: WCAG 2.2 A·AA. 이번 보고서는 주요 화면의 선택 항목 검토이며 앱 전체 준수 인증이 아니다.
- 우선 영역: A01 홈 → B01 사례 목록 → B02 해결 방법 → B03 문의 메시지. 기존 A02 입력 화면은 과거 검토 기록으로만 취급한다. 현재 검색 화면 A08·A09의 검사 결과로 대체하지 않는다.
- 팀 적용 기준 정리: 기존 디자인의 배치·리듬을 유지하며 읽기와 조작을 방해하는 요소를 우선 개선한다. 이번 채택 사항은 B02 준비물 텍스트 대비 개선이다. 별도의 팀 전원 승인 기록을 의미하지 않는다.

## 2. 대상 사용자와 해결할 상황
가상 사용자 민서(24세)는 자취 중이며 손목 불편으로 한 손으로 휴대폰을 사용한다. 작은 글자를 읽기 어렵고 주거 수리 용어에 익숙하지 않다. 사례를 선택하고 준비물·해결 단계를 확인하는 과정에서 희미한 글자, 작은 조작 영역, 불명확한 이름 때문에 다음 행동을 놓치지 않게 한다. 실제 사용자 조사 결과가 아닌 워크숍 시나리오다.

## 3. 점검 기준
| 영역 | 적용 기준 | 방법 |
|---|---|---|
| 글자 대비 | WCAG 1.4.3 AA: 일반 글자 4.5:1 이상, 큰 글자 3:1 이상 | 실제 전경·배경 색상과 불투명도로 상대 휘도 계산 |
| 색상·상태 | 1.4.1 A, 1.4.11 AA: 색상만으로 의미 전달 금지, 필요한 UI 경계·상태 대비 3:1 | 아이콘·문구·상태를 함께 확인 |
| 좁은 화면·확대 | 1.4.10 AA: 320 CSS px 리플로우, 1.4.4 AA: 글자 200% 확대 | 잘림·겹침·양방향 스크롤 확인 |
| 조작 영역 | 2.5.8 AA의 24×24 CSS px 또는 해당 예외. Android는 48×48dp 권장 | 시각 크기와 실제 터치 영역을 구분 |
| 이름·구조 | 1.1.1 A, 1.3.1 A, 4.1.2 A | 장식 이미지 중복 낭독 방지, 목록 구조·컨트롤 이름·펼침 상태 확인 |
| 키보드·시트 | 2.1.1 A, 2.1.2 A, 2.4.3 A, 2.4.7 AA | 초점 이동·순환·닫기·원위치 복귀 확인 |
| 안내 문구 | 3.3.1 A, 3.3.2 A | 입력 목적과 오류 원인·다음 행동을 글로 안내 |

큰 글자는 24 CSS px 이상 또는 굵은 글자 약 18.67 CSS px 이상을 기준으로 구분한다. 14px 준비물 글자는 일반 글자 기준을 적용한다. Android dp와 웹 CSS px는 시험 환경을 구분하여 기록한다.

## 4. 판단과 기록 규칙
- 높음: 핵심 과업 수행 불가 / 중간: 읽기·조작에 뚜렷한 어려움 / 낮음: 편의·일관성 저하. 심각도는 WCAG A·AA 수준과 별개다.
- 기록 항목: 화면, 위험, 관찰 근거, WCAG, 심각도, 개선안, 전후 화면, 재측정 결과.
- Figma 색상 검사, 웹 DOM·키보드 검사, Android 기기 검사를 서로 대체하지 않는다.
- LLM 제안은 후보이며 실제 측정값과 구현을 확인한 항목만 결과로 기록한다. 검사를 하지 않은 항목은 통과로 표시하지 않는다.
