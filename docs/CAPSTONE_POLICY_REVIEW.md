# 전시 프로토타입 안내 검토 (2026-11-24)

## 확인한 사항
- 디자인 트랙의 prototype-policy.ts와 PrototypeTermsScreen.tsx만 정책/UI 문구 변경. 출시 앱 정책, YouTube 문단, AI 실행 로직은 유지.
- AI 요청: api/index.mjs에서 미국 지정 OpenAI API 구성 사용. 응답 저장 비활성화.
- 커뮤니티는 React 메모리 상태, 최근 사례는 기기 저장.
- Vercel 배포의 Upstash Redis는 횟수·요청 ID 예약을 저장. 예약 90일 만료, 기간 카운터는 예약 시 90일로 갱신. 원문·사진·답변은 저장하지 않음.
- 약관 화면의 AI 준비 중 문구 제거. 실제 이용 가능 여부는 서버 시연 기간과 한도가 결정.

## 배포 설정 확인이 필요한 사항
- Vercel 실제 함수 리전·로그 보관, Upstash 실제 DB 국가·계약상 처리/보관 조건은 저장소만으로 확인 불가. 국외 이전 상세 안내 확정에 필요.
- 동의 체크값은 기기에 저장하나 현재 캡스톤 분석 요청에서 이 값을 검사하는 연결을 찾지 못함. 서버 동의 증빙·철회 기능도 없음. 문구 수정이 동의 처리 구현이나 법적 준수 완료를 뜻하지 않음.
- 정책 문구 작성 단계에서는 배포·외부 서비스 설정을 변경하지 않음. 이후 로컬 미리보기 API 연결 확인에서 가상 증상 1회 요청으로 기존 사례 응답 200을 확인함. 과금 여부는 제공사 사용 기록 별도 확인 대상.

## 분석 화면·문의 화면 변경 확인
- 문의 문장 선택 UI를 제거하고 직접 편집·복사·외부 SMS 작성 화면 연결로 변경. 전화번호/연락처 조회, 자동 전송, 새 SDK·권한 추가 없음. 데스크톱에는 복사 이용 안내를 표시함.
- 프로토타입 약관의 문의 기능 설명만 실제 동작에 맞춤. YouTube 문단·API 및 Android 설정 유지.
- 분석 설명 프롬프트는 관찰 증상과 가능한 발생 원리를 구분하도록 수정. 원인 확정 금지·안전 안내·책임 enum·전송 대상·store:false 유지. 버전 갱신으로 기존 응답 캐시와 구분함.
- 로컬 프롬프트 수정은 운영 중인 Render 서버에 아직 배포되지 않음. 기존에 생성·저장된 설명은 자동으로 다시 생성되지 않음.
- 이번 UI 검증은 가상 API 응답으로 수행함. 실제 휴대폰 SMS 앱 연결과 변경 프롬프트의 실제 모델 응답은 별도 확인 대상.

## 완료 후 후기 초안 및 배포 상태
- 해결 완료 후 공유를 선택하면 기존 결과로 후기 초안을 기기 안에서 채움. 추가 AI 호출·자동 게시 없음. 안내받은 단계와 사용자가 실제로 수행한 조치를 구분하며, 직접 경험은 사용자가 편집함.
- Render는 로그인 화면까지만 확인. 사용자 요청으로 재배포 중단했으며 서버·환경변수·한도·활성화 상태를 변경하지 않음. 설명 프롬프트 수정은 로컬에만 존재함.

## 2026-11-25 전달 전 확인
- 해결 완료 기록은 기기 localStorage에 저장하며 기존 사례 ID 또는 생성 결과 내용을 보관함. 서버 전송/공유 저장은 추가하지 않음. 마이 해결 건수는 해당 기록에 연결.
- 검색 복귀 및 후기 표시 모션 변경은 클라이언트 상태 처리만 변경. 외부 서비스, SDK, Android 권한, YouTube 설정 변경 없음.
- 웹 로컬 검증 및 프로덕션 빌드 확인. 실제 휴대폰·운영 분석 서버·국외 이전 안내의 미확인 사항은 위 기록대로 남음. 출시 승인이나 정책 준수 완료를 의미하지 않음.
