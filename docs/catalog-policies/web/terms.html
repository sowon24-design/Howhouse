제1조 목적 및 운영자

제2조 제공 기능

- 카테고리별 기존 사례와 준비물·해결 순서 조회

- 기기에 포함된 사례와 검색 사전을 이용한 관련도 검색

- 기존 사례 문의 문장의 선택·직접 편집·복사

- 사용자가 선택한 외부 영상 링크

예약·중개·결제·자동 메시지 전송은 제공하지 않습니다. 사례 검색과 문장 편집은 기기 안에서 처리하며 외부 링크 이용에는 해당 서비스의 이용 환경이 필요합니다.

제3조 안내의 한계와 안전

사례는 일반적인 참고 정보입니다. 원인·소요 시간·수리 비용 부담은 실제 현장, 계약과 원인에 따라 달라지며 현장 점검·법률 자문·확정 판단을 대신하지 않습니다. 검색 순위는 진단이나 안전 보증이 아닙니다. 전기·가스·화재·누수 등 위험이 의심되면 작업을 중단하고 안전을 확보한 뒤 긴급기관 또는 전문가에게 도움을 요청하세요. 앱은 현장 출동이나 긴급 대응을 제공하지 않습니다.

제4조 이용자의 의무

타인의 권리를 침해하거나 불법적으로 서비스를 이용해서는 안 됩니다. 무단 접근·운영 방해·허용 범위를 넘는 콘텐츠 복제 및 배포를 해서는 안 됩니다. 문의 문장은 실제 상황에 맞게 확인·수정한 뒤 직접 사용합니다.

제5조 콘텐츠와 이미지

사례 문장은 팀 자체 제작 자료이며 캐릭터와 대표 사진은 팀이 AI로 제작한 설명용 이미지입니다. 실제 이용자의 사진이나 문제 현장의 증거가 아닙니다. 콘텐츠 권리는 정당한 권리자에게 있으며 제3자의 권리와 관계 법령을 존중합니다.

영상 링크는 YouTube로 이동합니다. 썸네일에는 YouTube API Services를 사용하며 해당 기능 이용 시 YouTube 이용약관(https://www.youtube.com/t/terms?hl=ko)이 적용됩니다. 온보딩의 서비스 이용약관과 개인정보 처리방침에서 썸네일 관련 안내를 확인합니다. 썸네일 조회 여부와 관계없이 사례 검색과 문의 문장 편집은 기기 안에서 처리합니다. 외부 사이트에는 해당 업체의 정책이 적용되며 앱이 구매·서비스 이행을 대신하거나 제휴·보증하는 것은 아닙니다. 약관·정보 안내 링크는 Notion 공개 페이지로 이동합니다. 문의 문장은 복사 후 이용자가 수신자와 전송 여부를 결정합니다. 메일 문의도 외부 메일 앱에서 사용자가 직접 보냅니다.
