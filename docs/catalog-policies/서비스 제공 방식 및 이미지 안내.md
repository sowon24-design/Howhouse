## 사례 검색과 안내
어쩌집은 미리 준비한 주거 문제 사례와 해결 순서를 안내합니다. 입력한 단어·증상과 가까운 사례를 기기 안에서 찾아 보여드립니다. 검색 결과는 원인을 진단하거나 안전을 보증하는 결과가 아니며, 일치하는 사례가 없으면 검색어를 바꾸거나 카테고리에서 찾아볼 수 있습니다.

사례 문장은 운영팀이 작성했으며 캐릭터와 대표 이미지는 AI를 활용해 미리 제작한 설명용 이미지입니다. 실제 이용자의 사진이나 문제 현장을 촬영한 자료가 아니며 특정 원인을 입증하지 않습니다.

준비된 문장을 선택하고 상황에 맞게 직접 수정할 수 있습니다. 복사한 문장은 기기 클립보드에 기록되며 자동으로 전송되지 않습니다. 받는 사람과 내용을 확인한 뒤 외부 앱에서 직접 보내 주세요.
