# YouTube 썸네일·개인정보 안내·Android 코드 2 변경 내역

2026년 11월 12일, main `bd25f583`(PR #67 반영) 대비 변경이다. AI 없는 기존 사례 앱을 유지하며, 사용자가 승인하고 휴대폰에서 확인한 상태를 PR로 전달한다.

## 사용자에게 보이는 변경

- 사용자 요청에 따라 홈·온보딩·검색·마이 페이지·B 화면과 반응형 기준을 PR #66 상태로 복원했다. main의 PR #67 화면을 그대로 유지하는 변경이 아니다. `CatalogApp.tsx`, 관련 화면/CSS, 앱 아이콘도 이 기준에 포함된다.
- 영상 썸네일은 앱에 넣어 둔 JPG 대신 YouTube Data API v3의 현재 공개 영상 정보로 조회한다. 영상 영역이 보이고 현재 개인정보 안내 확인이 저장된 경우에만 자동으로 요청한다.
- 썸네일 중앙에 공식 원본 흰색 YouTube 아이콘을 표시한다. 썸네일과 아이콘 사이에는 사용자가 승인한 검정 20% Multiply 레이어를 둔다. 별도 미리보기 버튼·영상 제목·채널명 안내를 추가하지 않았다.
- 준비물은 외부 연결 없는 태그다. 실제 앱에서는 외부 이동 아이콘·쿠팡 연결·클릭 동작이 없다. 공통 컴포넌트의 콜백 계약은 기존 미리보기와의 호환을 위해 보존한다.
- 검색·사례 열기·문의 문장 편집/복사는 오프라인에서도 동작한다. 영상 정보와 외부 YouTube 이동에는 인터넷이 필요하다.

## 개인정보·보안

- 앱 원본 `src/catalog/policy.ts`와 로컬 문서 6종·HTML 사본을 동기화했다. 소원 트랙 공개 문서의 YouTube 처리 안내와 대조한 기록을 포함한다. 시행일은 2026년 11월 10일, YouTube 관련 정리일은 11월 12일이다.
- 정책 버전 `catalog-2026-11-12-youtube-v2`를 기기에 저장한다. 이전 버전 확인 기록만으로 새 썸네일 요청을 허용하지 않는다. 기존 이용자는 새 안내 확인을 닫고 사례를 이용할 수 있으나, 현재 안내를 확인하기 전에는 새 썸네일을 요청하지 않는다.
- 공개 영상 ID와 공통 프로젝트/앱 식별정보로 Google에 직접 HTTPS 요청한다. 닉네임·검색어·문의 문장·사용자 사진·OAuth 토큰은 요청에 넣지 않는다. Google이 받는 IP·HTTP 정보와 일반 처리/보관/권리 행사 링크를 안내한다.
- 요청에 쿠키·referrer를 보내지 않으며 자동 재시도나 영구 이미지 캐시를 만들지 않는다. 중단·백그라운드 전환 시 요청을 취소하고 메모리 이미지 URL을 해제한다. 응답 호스트와 공개 영상 여부를 검사한다.
- CSP는 Google API와 이미지 조회에 필요한 호스트만 허용한다. AI·기존 서버·Camera/Network 런타임 모듈의 배포 포함 차단을 유지한다.
- YouTube 키는 제한된 추출 가능 클라이언트 키다. 실제 키 값·환경 파일·서명 키·비밀번호는 이 PR에 없다. 개발자는 별도로 키와 Android 패키지/인증서 제한을 설정해야 한다.
- 법적 무위험이나 Play 심사 통과를 보증하는 변경이 아니다. 개별 확인 범위와 해석의 한계는 검토 문서에 구분했다.

## Android 및 Play 확인 결과

- 영상 조회용 INTERNET 권한을 추가했다. 카메라·사진 권한은 추가하지 않았다.
- 확인용 `youtubeQa` 빌드와 실제 출시 빌드의 검증 조건을 구분했다. production 빌드는 Play 앱 서명 SHA-1과 개인정보/Android 확인값을 검사한다.
- release에 R8을 켜고 최적화 기본 규칙과 Capacitor의 플러그인 보존 규칙을 사용한다. `mapping.txt`를 만들기 위해 버전 1.0 / 코드 2로 빌드했다.
- 코드 2 APK/AAB 서명 검증, bundletool 구조 검사, 웹 자산 297개 일치, AAB 내 `proguard.map`과 별도 매핑 파일 해시 일치를 확인했다.
- AAB SHA-256: `1e4bfe4dfa52429085c8230f3748979ce9d42d8500c53bad7158d22effef3e23`.
- APK SHA-256: `214ad8317d2e452517b4556aaa51e1468a57ed958c7b8f5ef48b2f1cda23772e`.
- Alpha에 코드 2를 업로드·저장했다. Play가 ReTrace 매핑 첨부를 인식했고 가독화 파일 경고는 사라졌다. 코드 1은 대체된 상태다.
- 남은 경고는 테스터 미지정 1개다. 테스터 이메일은 사용자가 입력하며, Google 심사 전송·테스트 배포·공개 출시는 아직 하지 않았다.

## 검증

- 검색·콘텐츠 안전·YouTube 응답/오류·현재 정책 확인·출시 설정 검사 92개 통과.
- 사례 데이터·추가 사례·문의 문장/해결 상태 검사 22개 통과.
- TypeScript 타입 검사, 공통 기반 검사, 정책 사본 6종 동기화 검사, catalog-preview 빌드 통과.
- 실제 갤럭시에서 검색/뒤로가기 유지, 문의 수정·복사·재진입 보존, 썸네일/외부 이동/앱 복귀, 오프라인 핵심 기능, 문서 열람, 닉네임/시작 설정 유지·초기화를 사용자 확인했다. R8 코드 2에서도 검색·뒤로가기·문의 수정/복사·YouTube 표시/이동·기존 UI 유지가 정상임을 다시 확인했다.
- 실제 Play가 재서명한 설치본의 YouTube 동작은 비공개 테스트 배포 후 확인해야 한다. 직접 설치 APK의 성공과 구분한다.
