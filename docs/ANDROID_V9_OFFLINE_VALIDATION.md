## 검증 방법과 재사용한 기록

실제 앱 UI는 승인 차단을 유지했다. 그 앱의 WebView에서 별도의 테스트 하네스로 같은 클라이언트 모듈을 실행하고 전용 전송만 로컬 HTTP 서버/PGlite에 연결했다. 테스트 서버의 합성 인증·모델·승인 의존성은 하네스에만 존재한다. 앱의 정상 미승인 버튼으로 분석·철회·삭제 화면 전체를 통과했다고 주장하지 않는다.

v9 로컬 통합은 합성 모델 2회, 실제 OpenAI 0회, 운영 DB 쓰기 0회였다. 삭제는 해당 로컬 DB의 연결 자료 검사이며 공급자 전체 로그·백업 삭제 입증이 아니다.

사진 디코더·파일명/EXIF/GPS 제거 코드는 v7 이후 바뀌지 않았다. 이전 Android 사진 형식·방향·손상·취소·인코더 실패 검증을 재사용해 전체 사진 시험을 반복하지 않았다. 이번에는 v9 동의 연결에 필요한 합성 사진 한 종류만 처리했다. 사용자 카메라·보관함 사진은 새로 수집하거나 전송하지 않았다. v9 직전 타입·동기화·테스트235개 결과도 불필요하게 반복하지 않았다.

가상기기의 느린 초기 로딩에 맞춰 화면 준비 대기를 보완했다. 첫 테스트 중단과 로컬 통합 대기 초과는 하네스를 조정하여 재실행했고 최종 통과 결과만 아래 파일에 저장했다. 앱 제품 코드 수정은 필요하지 않았다.
