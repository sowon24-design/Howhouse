# 사례 CSV 및 준비물 검색 연결

2026-11-05 사용자 승인 CSV 검토본을 앱의 원본 CSV 4개에 반영했다. E열은 짧은 명사형 제목, F열은 구매용 준비물이다. 사례 번호·행·열 위치와 기존 영상·단계·책임 관련 값은 유지했다. 가전 32번 삭제 처리 및 해충 46·53·54번의 빈 행은 유지했다. 활성 사례는 53개다. Google Sheets 원본은 변경하지 않았다.

대상 없음 7건은 집주인 대상과 문의 문장 4개를 같은 열에 추가했다. 활성 사례의 대상은 집주인 전용 9개, 집주인·전문 업체 44개다. 해결·미해결 양쪽에서 기존 문의 화면으로 이동한다. 집주인 전용 안내에는 전문 업체를 언급하지 않는다. 문의는 초안 수정·복사 기능이며 사용자가 직접 전송한다.

준비물 버튼은 품목명만 URL 인코딩한 일반 쿠팡 검색으로 연결한다. 제휴 ID나 사례·사용자 정보를 추가하지 않는다. 웹은 새 탭, Android는 Capacitor의 외부 URL 처리(ACTION_VIEW)를 사용한다. 규격·호환성 및 대체재 사용은 원래 해결 단계 안내를 따른다. 구매 목록에서 제외된 설명서·물·컵 등이 해결 단계에서 불필요해진 것은 아니다.

## 검증

- 데이터·메시지·검색 URL 테스트 16개 통과.
- TypeScript 검사, 공통 에셋 검증, 프로덕션 빌드 통과.
- Edge 자동 확인: 구연산 버튼이 정확한 검색어와 새 탭 옵션을 전달한다. 외부 쇼핑 사이트 요청은 테스트에서 실행하지 않았다.
- 기존 문의 대상 없음 사례 9번이 해결·미해결 양쪽에서 집주인 전용 B03으로 연결되고 문의 초안이 표시된다.
- Pretendard 32px/700으로 측정한 전체 제목 최대 폭 236px. 320px 화면의 좌우 24px 여백을 제외한 272px 안에 들어간다. 저장 사례 제목은 좁은 폭·글자 확대 시 한 줄 말줄임, 전체 문구는 DOM과 title에 유지한다.
- Android 실기기의 쿠팡 설치/미설치 각각의 외부 전환과 복귀는 직접 확인해야 한다. APK 재설치·배포는 수행하지 않았다.

## 실행 및 직접 확인

`npm run dev`로 실행한다. `/src/solutions/preview.html`에서 B 화면을 독립 확인할 수 있다. 실제 앱 홈에서도 사례를 열어 준비물 클릭, 외부 앱 복귀, 문의 초안 편집·복사를 확인한다. 준비물이 빈 난방 16번은 0단계 구매 영역을 표시하지 않아야 한다.

자동 검사:

```sh
node --test src/solutions/data/verify-data.test.mjs src/solutions/message-model.test.mjs src/solutions/supply-links.test.mjs
npm run build
npm run verify:foundations
```
