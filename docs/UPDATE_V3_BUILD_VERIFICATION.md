## 실제 기기 확인

동일 main 소스의 직접 설치용 확인 APK를 갤럭시에서 사용자와 확인했다.

- YouTube 썸네일 표시, 영상 열기, 앱 복귀 정상.
- 수정한 메시지 본문과 줄바꿈이 외부 메시지 작성 앱에 전달되고, 복귀 후 수정 내용 유지. 외부 앱에서 복귀할 때 재실행 로딩 없음.
- 앱 아이콘 재진입 및 완전 종료 후 실행에서 기존 로딩 후 정상 진입하고 닉네임·이용 설정 유지.
- 테스트에서 실제 문자 발송을 요청하거나 수행하지 않았다.

## 별도 확인이 남은 항목

- Play 업로드를 하지 않았으므로 Google이 재서명한 실제 Play 설치본의 최종 동작은 미확인이다.
- 정책 버전과 승인 자료는 `catalog-2026-11-12-youtube-v2`, 시행일은 2026-11-10이다. PR #71의 11월 21일 메시지 앱 안내 개정에 대한 적용일·기존 사용자 재확인 필요 여부·승인 증빙의 최신성은 별도 검토가 남는다.
- 앱 원문과 저장소 정책 문서 6개는 일치한다. 공개 Notion 최신 본문 재대조 및 이번 APK에서 현재 약관을 별도로 열어 확인했다는 명시적 응답은 미확인이다.
- 정책 버전·날짜·출시 승인값을 임의로 바꾸지 않았다. 이 기술 검증은 정책 적합성 인증 또는 출시 승인 판정이 아니다.
