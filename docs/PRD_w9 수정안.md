## 1. 서비스 정의와 목표

**한 줄 정의:** 자취생 생활문제 해결 서비스.

자취방 생활문제를 처음 겪는 대학생이 사례 기반 해결 방법을 단계별로 따라 하며 스스로 대응하도록 돕습니다. 스스로 해결하기 어려운 경우에는 집주인 또는 전문 업체(수리 기사)에게 보낼 문의 메시지를 작성해 다음 행동을 이어 줍니다.

목표는 학기 안에 **Android 앱**으로 출시 가능한 범위를 완성하는 것입니다. 출시 일정과 완료 기준은 팀이 확인합니다.

## 2. 문제 정의와 배경

자취 초보 대학생은 누수·악취·해충·보일러 고장 등을 발견해도 검색 결과의 원인 후보가 너무 많아 무엇부터 확인할지 모릅니다. 해결책 자체뿐 아니라 현재 상황이 얼마나 심각한지, 지금 무엇을 해야 하는지 알고 싶어 합니다.

원문은 책임 소재의 불확실성보다 불편의 심각도, 일정·방문 전 정리 부담, 낯선 사람을 집에 들이는 부담이 문제 해결을 미루는 주요 원인이라고 설명합니다.

### 원문에 기재된 조사 배경 — 근거 확인 필요

- 대학교 UX 수업 캡스톤 프로젝트로 자취 경력 3년 이내 대학생을 인터뷰·설문했습니다.
- 150개 인사이트를 어피니티 다이어그램으로 묶어 정보 탐색·타인 의존·미루기의 세 테마를 도출했습니다.
- 사용자 투표와 로파이 롤플레잉 검증을 거쳐 해결사례 도서관과 SOS 모드를 우선 범위로 정했습니다. 이후 사용성 테스트에서 SOS 모드를 쓴 참여자가 없어 범위에서 제외했습니다.
- 9주차 개발 착수 시점에 커뮤니티와 수리업체 찾기도 범위에서 제외했습니다(0.1 참고).
- **팀 확인:** 조사 자료 링크, 참여자 수, 진행 시점, 검증 결과를 연결해야 합니다. 이 문서에는 해당 근거가 첨부되어 있지 않습니다.

## 3. 대상 사용자

- 주 사용자: 자취 생활문제를 처음 겪는 대학생.
- 조사 대상 범위: 자취 경력 3년 이내 대학생(원문 기준).
- 사용 기기: **Android 앱** (사진 선택·카메라·권한 안내는 Android 시스템 UI 기준).
- 카테고리: 라이프스타일 / 일상.

### 원문 페르소나: 김서윤

서울 동작구 상도동의 다세대주택 3층 원룸에 사는 22세 대학생으로, 자취 6개월 차입니다. 검색·지도·카카오톡에는 익숙하지만 수리와 시설 지식은 거의 없습니다. 평일 낮에는 수업으로 집을 비우고, 방문 일정 조율과 낯선 사람의 방문을 부담스러워합니다. 집주인에게 연락하기 전 문제의 범위를 판단하고 스스로 적절히 대응하고 싶어 합니다.

| 기능 | 사용자 행동과 제공 내용 |

| 마이 페이지 | 닉네임 확인·수정, 앱 정보, 개인정보 및 데이터 관리, 이용약관, 개인정보 처리방침, 문의하기. |

### 4.1 화면별 요구사항

**진입 흐름 (온보딩 · 약관 동의 · 닉네임)**

- 첫 실행 시 온보딩 3장(혼자 고민하지 마세요 / 말해주면, 방법을 찾아드려요 / 혼자 사는 마음까지 든든하게)을 보여줍니다. 시작 화면의 버튼은 '시작하기', 이후 장은 '다음으로'입니다.
- 약관 동의 화면에서 [필수] 서비스 이용약관, [필수] 개인정보 처리방침에 동의해야 '동의하고 시작하기'가 활성화됩니다. '모두 동의' 체크, 항목별 '보기'(바텀시트로 약관 전문 열람, '닫기')를 제공합니다.
- 닉네임 설정: "어떻게 불러드릴까요?" 입력창(0/10)에 한글·영문·숫자 조합 10자 이내로 입력합니다. 입력 전에는 '다음으로'가 비활성이고, 입력하면 '시작하기'가 활성화됩니다. 형식이 맞지 않으면 "한글·영문·숫자 조합의 10자 이내의 닉네임으로 입력해 주세요." 오류를 표시합니다.
- 닉네임 중복 허용 여부, 금지어 기준은 미정입니다.

**홈**

- 상단에 "{닉네임} 님! 어떤 도움이 필요하세요?"와 마이 페이지 진입 아이콘을 둡니다. 하단 탭은 두지 않습니다.
- "우리집 문제에 대한 해결 방법을 찾아 볼까요?" 배너로 문제 직접 작성 화면에 진입합니다.
- "어떤 문제를 해결할까요?" 영역에 카테고리 8개(보일러·화장실·냉장고·수도·수질·전기·조명·세탁기·해충·곰팡이)를 아이콘으로 보여줍니다.
- "{월}에 많이 찾는 문제예요" 영역에 인기 문제 3개를 보여주고, 누르면 해당 해결 사례로 이동합니다. 산정 기준(조회 수, 기간)은 미정입니다.
- "다른 자취생들이 많이 본 이야기" 영역(제목·요약·썸네일·반응 수·작성 시점·작성자)이 화면에 있습니다. 커뮤니티를 제거했으므로 이 영역의 성격(운영 콘텐츠인지)과 유지 여부는 팀 확인이 필요합니다.

**문제 입력(직접 문제 작성하기)과 분석**

- "어떤 문제가 생겼나요?" 화면에서 '문제 상황' 텍스트와 '사진 첨부하기(최대 5장)'로 문제를 입력합니다. 입력 전에는 '지금 해야 할 일 보러가기' 버튼이 비활성입니다.
- 사진 추가는 '사진 찍기' 또는 '사진 보관함에서 선택하기'를 고르는 바텀시트로 시작하며, 카메라·사진 접근 권한은 Android 시스템 권한 안내(제한된 액세스 허용·모두 허용·허용 안 함)를 따릅니다. 첨부한 사진은 개별 삭제(✕)할 수 있습니다.
- 버튼을 누르면 "어디가 문제인지 알아보고 있어요. 최대 1분 정도 걸려요." 분석 화면으로 가며, 이 동안 버튼은 '잠시만 기다려 주세요'로 비활성입니다. 분석 후 해결 사례 페이지로 이동합니다.
- 음성 입력은 키보드에 내장된 기능을 사용하도록 합니다.
- 분석 실패·네트워크 오류 시 "정보를 불러오지 못했어요. 네트워크를 다시 확인해 주세요." 화면과 '다시 시도하기' 버튼을 보여줍니다.

**카테고리 · 해결 사례 선택**

- 홈에서 카테고리를 고르면 "{카테고리} 카테고리" 화면에서 "나의 상황과 가장 비슷한 문제를 골라주세요." 목록(예: 화장실 — 욕실 배수구에서 냄새가 나요, 배수구에 물이 고여서 내려가지 않아요, 곰팡이가 생겼어요, 환기팬을 작동시켜도 환기가 잘 안 돼요, 변기가 막혔어요, 바닥에 물이 자꾸 고여요, 타일이 깨졌어요)을 보여줍니다.
- 목록에 원하는 문제가 없으면 '내 문제를 찾을 수 없어요'로 이어집니다. 이후 화면(직접 작성 연결 여부)은 최종 화면에 없어 확인이 필요합니다.

**해결 사례 페이지(해결 방법)**

- 상단 이미지, 문제명(예: 싱크대 누수), 원인 설명, 예상 소요 시간, 배상 책임을 보여줍니다. 배상 책임 값은 현재 화면에서 '-'로 표시됩니다.
- '해결 방법'에는 준비물 칩(예: 마른 수건, 물받이)과 가로 스와이프 단계 카드(진행 바, 이전·다음 버튼)를 둡니다.
- 단계 문장에 낯선 부품·용어가 나오면 카드 안에서 바로 풀어 씁니다. 예: "연결부 너트(배수 호스와 배관을 잇는 둥근 조임 부품)를 손으로 조이거나, 패킹(연결 부위 사이에 끼우는 고무 링)을 교체해요." 아코디언으로 펼쳐 보는 라인드로잉 상세 이미지는 넣지 않습니다.
- '더 자세히 알아보기'는 외부 링크로 연결되는 이미지 카드입니다. 해결 방법을 더 직관적으로 보여줄 수 있는 유튜브 영상의 링크가 첨부됩니다.
- 하단에 '문의 메세지 작성하기'와 '완료' 버튼이 있습니다. '완료'버튼을 누르면 메인 화면으로 이동합니다. 집주인이나 전문업체 등 외부의 도움이 필요할 수 있는 사례인 경우 '문의 메세지 작성하기'버튼이 활성화됩니다. 그렇지 않을 경우 '완료'버튼만 존재합니다.
- 우상단 ⋮ 메뉴에서 의견 보내기를 열 수 있습니다.
- 이전 PRD의 난이도·해결 방식, '비슷한 상황의 이야기', '근처 수리 업체 찾기' 버튼은 최종 화면에 없습니다.

**의견 보내기**

- "어떤 점이 아쉬웠나요?" 바텀시트에서 라디오로 하나를 고릅니다: 내 상황과 달라요 / 방법이 틀린 것 같아요 / 따라하기 위험해 보여요 / 어려워 보여요 / 필요한 준비물·정보가 빠졌어요 / 직접 입력하기.
- 직접 입력하기를 고르면 입력창이 나타나고(안내 문구가 "신고 사유가 무엇인가요?"), 선택 후 '의견 보내기'가 활성화됩니다. 의견 수집 방식과 처리 담당은 미정입니다.

**문의 메시지 작성하기 (집주인 / 전문 업체)**

- 상단 탭으로 '집주인'과 '전문 업체'를 전환합니다. 라벨은 "집주인에게 보낼 메세지", "수리 기사에게 보낼 메세지"로 바뀝니다.
- 해결 사례에서 가져온 문장으로 메시지 초안을 자동 구성합니다. 예: 인사 → 증상 → 조치 내용 → 요청 → 마무리.
- "메시지에 넣을 내용을 선택해 주세요" 버튼을 누르면 "메세지에 포함할 문장을 선택해 주세요." 바텀시트가 열립니다. 문장은 체크(포함)와 +(추가)로 구분하고 '취소하기'·'수정하기'로 확정합니다.
- 미리보기 카드를 눌러 문장을 직접 수정할 수 있습니다("메세지창을 클릭해서 직접 수정할 수도 있어요" 안내).
- '메세지 복사하기'를 누르면 클립보드에 복사하고 "메세지를 복사했어요." 토스트를 보여줍니다. 하단 안내는 "복사한 뒤 문자에 붙여넣어 주세요."입니다. 앱이 메시지 앱을 직접 열거나 전송하지는 않습니다.
- 이전 PRD의 '블록' 용어 제거, 취소선 제거, 긴급 전용 문장 제거 방침은 유지합니다. 제목을 한 줄로 줄여 첫 화면에 메시지 전체와 복사 버튼이 함께 보이게 하는 방침도 유지합니다.
- 복사 후에도 화면은 유지됩니다. 자동으로 이동하지 않습니다.

**마이 페이지**

- 닉네임 카드(수정 아이콘)에서 닉네임 설정 화면으로 이동해 수정합니다. 규칙은 온보딩과 같고 버튼은 '수정하기'입니다.
- '데이터' 영역: 앱 정보(서비스명·버전 v1.0.1·서비스 소개·운영 주체·문의·처리방침·이용약관 안내), 개인정보 및 데이터 관리(내 정보와 데이터 관리, AI 분석 정보, 게시글 및 활동 정보, 데이터 삭제 및 개인정보 문의 안내, '외부 링크에서 보기'·'확인했어요'), 이용약관, 개인정보 처리방침, 문의하기('이메일 복사하기').
- 이전 PRD의 '우리 집 문제 기록'과 홈의 '최근 확인한 문제'는 최종 화면에 없습니다. 유지 여부를 정해야 합니다.

### 차별점

일반 검색처럼 정보를 나열하는 데서 그치지 않고, 증상에 맞는 해결 방법을 단계별로 안내하고 어려운 경우 집주인·전문 업체에 보낼 메시지까지 이어 줍니다.

- **커뮤니티**(글 목록·검색·글쓰기·도움돼요·댓글). 9주차 기획 변경으로 제외했습니다.
- **주변 수리업체 찾기**(카카오맵 로컬 API 검색, '카카오맵에서 보기'). 9주차 기획 변경으로 제외했습니다.

- 업체 리뷰·평점·가격 표시.

- iOS 지원.

## 5. 사용자 시나리오

### 시나리오 1: 욕실 악취

1. 사용자가 홈에서 화장실 카테고리를 고르고 "욕실 배수구에서 냄새가 나요"를 선택합니다.
2. 해결 방법의 준비물과 단계 카드를 넘겨 보며 배수구 이물질이나 트랩 문제를 확인합니다.
3. 사례의 해결 단계를 따라 조치한 뒤 냄새가 줄었는지 확인하고 '완료'를 누릅니다.
4. 문제가 해결되지 않으면 '문의 메세지 작성하기'로 집주인에게 보낼 메시지를 만듭니다.

### 시나리오 2: 싱크대 아래 누수

1. 사용자가 싱크대 수납장 아래에서 물이 새는 것을 발견하고, 홈 배너로 '직접 문제 작성하기'에 들어가 문제 상황을 쓰고 사진을 첨부합니다.
2. 서비스가 분석한 뒤 '싱크대 누수' 해결 방법을 보여줍니다.
3. 사용자가 준비물을 챙기고 단계 카드를 따라 새는 곳을 찾고, 카드 안의 용어 풀이를 보며 연결부 너트를 조이거나 패킹을 확인합니다.
4. 해결되지 않으면 '문의 메세지 작성하기'에서 집주인 또는 전문 업체 탭을 고르고, 포함할 문장을 선택·수정합니다.
5. '메세지 복사하기'로 복사한 뒤 문자 앱에 붙여넣어 직접 보냅니다.

> 위 내용은 제품 사용 흐름의 예시입니다. 실제 안내 문구와 상황별 안내 순서는 검증 후 확정해야 합니다.

## 7. 위험 요소와 대응 방향

- **사진 분석 오류:** 부정확한 분석이나 낮은 촬영 품질로 잘못된 행동을 권할 수 있습니다. 직접 카테고리를 고르는 경로와 '내 문제를 찾을 수 없어요' 경로가 필요하며, 분석 실패 화면(다시 시도하기)을 둡니다.
- **위험 상황 안내:** 긴급 모드를 제외했으므로, 누수·누전처럼 위험할 수 있는 문제의 해결 단계에는 '위험하다고 느껴지면 119 또는 관리실에 연락하세요' 같은 안전 문구를 일반 화면 안에 둡니다. 현재 해결 사례 화면에는 이 문구가 보이지 않아 추가해야 합니다(이용약관 제3조의 안내와 일관되게).
- **해결 방법 신뢰성·의견 수집:** 잘못된 정보나 위험한 방법이 안내될 수 있습니다. 의견 보내기 응답을 검토해 사례를 수정하는 절차가 필요합니다.
- **개인정보:** 사용자가 입력한 문제 상황·사진이 AI 분석에 쓰입니다. 입력에 개인정보나 타인의 민감한 정보가 들어가지 않도록 안내하고, 보관·삭제 기준을 약관에 반영합니다.
- **책임 표시 한계:** 해결 사례 화면의 '배상 책임' 항목은 책임을 확정하는 것처럼 읽힐 수 있습니다. 표기 방식(참고용 표시, '-' 처리, 항목 제거)을 정합니다.
- **Android 환경 편차:** 기기·OS 버전별 카메라·사진 선택기·권한 동작이 다를 수 있습니다. 최소 지원 OS와 주요 기기 테스트 범위를 정합니다.
- **메시지 수동 전송:** 복사 후 붙여넣는 방식이라 사용자가 전송까지 마쳤는지 앱이 알 수 없습니다. 지표는 '복사' 기준으로 측정합니다.
- **안내 범위:** 비용·책임을 확정하거나 위험도를 과소평가하지 않도록 행동 안내·기록 지원의 범위를 정합니다.
