## 공식 근거와 판단

- [YouTube 개발자 정책 III.F.2](https://developers.google.com/youtube/terms/developer-policies)는 썸네일도 출처 표시 대상으로 명시한다. [브랜딩 지침](https://developers.google.com/youtube/terms/branding-guidelines)에 따른 표시가 필요하다. 외부 이동 아이콘·스크린리더 전용 문구만으로 대체할 근거는 확인하지 못했다. 현재 UI 동결과 충돌하므로 임의 추가하거나 준수 완료로 처리하지 않는다.
- 같은 정책 III.A는 자체 약관의 YouTube 약관 연결·적용 안내, Google 개인정보 정책 연결, 실제 처리 설명 및 정책 수락을 요구한다. 외부 영상 링크만 설명하는 기존 본문은 자동 API 조회를 설명하지 못한다.
- [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)에서 이 앱의 개별 API 연결 로그에 대한 정확한 처리 국가·보관 일수는 확정하지 못했다. 한국 또는 미국 고정, 무보관이라고 적지 않는다.
- [개인정보 보호법 제28조의8](https://www.law.go.kr/법령/개인정보보호법/제28조의8)의 적용 근거와 고지 항목을 검토해야 한다. Google의 직접 수집과 운영팀의 이전·위탁 해당 여부를 단정하지 않는다. 개발자 API 약관 동의나 정책 링크만으로 이용자 동의를 대신한다고 보지 않는다.
- [Play 데이터 보안](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko)은 일시 처리라고 설문에서 자동 제외하지 않는다. 외부 전송 없음이라는 이전 답변을 그대로 재사용하면 안 된다. IP만으로 앱이 위치를 추론한다고 단정하지도 않는다. 팀원이 진행 중인 설문은 직접 수정하지 않았다.

## 개인정보 본문용 사실 초안 — 미적용

> 어쩌집은 YouTube API Services를 이용합니다. 영상 카드가 화면에 나타나면 공개 영상 정보와 썸네일을 자동으로 요청합니다. 이 과정에서 Google에 영상 식별값, 앱/API 식별정보와 접속 IP·HTTP 연결 정보가 전달됩니다. 앱은 이 요청에 닉네임, 검색어, 문의 문장이나 사용자 사진을 넣지 않으며 YouTube 계정 로그인을 요청하지 않습니다.
>
> 조회 결과는 앱 메모리에 일시 표시하며 화면 이탈·앱 숨김 때 해제합니다. 이는 Google의 연결 기록 삭제와 다릅니다. Google 측 처리는 Google 개인정보처리방침에서 확인할 수 있습니다. 영상 재생은 이용자가 선택할 때 외부 YouTube 앱 또는 브라우저에서 이루어집니다.

이 문단은 완성된 국외 이전 동의서가 아니다. 법적 적용 근거·필요 고지와 실제 수락 절차를 확정해야 한다. 준비물 쿠팡 연결은 현재 미제공이므로 기존 본문의 해당 설명도 정정 대상이다. 공개 문서·앱 동기화와 시행일은 미적용이며 기존 동의로 소급하지 않는다.

## 최종 AAB 및 비공개 테스트 순서

1. 필수 출처 표시·개인정보 안내와 수락 절차 해결. 승인 JSON은 false 유지.
2. 팀원이 준비 중인 공개 정책 URL·데이터 보안·스토어 자료와 대조. 기존 AI 문서를 사용하지 않음.
3. Play 기존 업로드의 최대 버전 코드 확인. 초안에 파일이 없다는 이유만으로 코드1 재사용을 확정하지 않음.
4. Play 서명 지문 설정으로 빌드·동기화·AAB 서명. 비밀번호는 사용자가 직접 입력. 키는 Git·로그에 포함하지 않음.
5. 패키지·버전·서명·권한·포함 파일·정책 버전·해시 검증. QA APK와 이전 PR67 AAB는 새 제출본으로 사용하지 않음.
6. 최종 AAB와 테스터 명단 등록 후 Play 설치본 썸네일 확인. Console의 최소12명·연속14일 비공개 테스트 요건을 확인하고 프로덕션 액세스 신청.

현재 테스터12명 확보, 이메일 입력 대기. 업로드·초대·제출은 미실행. 모든 UI·문구를 동결하는 동안 현재 자동 썸네일 버전은 제출 보류다. 썸네일을 유지하려면 출처 표시와 필수 안내에 한한 변경 범위를 먼저 합의해야 한다. 업체 예외가 확인되지 않은 상태에서 조건 충족으로 간주하지 않는다.
