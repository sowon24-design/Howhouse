1. manifest의 URL과 맞는 기존 페이지를 열고 해당 Markdown 본문으로 교체합니다. 제목·링크·국가·보관 예외·거부 및 철회 안내를 생략하지 않습니다.
2. 페이지 URL/ID를 유지합니다. 변경해야 하면 앱 연결도 바뀌므로 먼저 공유해 주세요.
3. 로그아웃 상태에서 6개 URL의 공개 접근과 v9 본문을 확인합니다. 앱·서버에 사용될 버전/해시는 manifest와 대조합니다.
4. 반영한 URL과 확인 시각, 본문을 추가로 수정했는지 알려주세요. 수정이 필요하면 앱 원본에도 반영해야 하므로 Notion만 다르게 고치지 않습니다.
