# 콘텐츠·이메일 처리 검토 결과

2026-11-10. AI 없는 catalog 버전. 공식 약관 검토와 사용자 확인을 구분하며 법률 자문·심사 승인으로 표시하지 않는다.

## 콘텐츠

- 사용자 확인: 사례 문장은 팀 자체 제작, 캐릭터·대표 사진은 GPT로 직접 생성.
- OpenAI 개인용 약관은 법이 허용하는 범위에서 사용자와 OpenAI 사이 출력물 권리를 사용자에게 부여한다. 그 자체로 앱에 정적 이미지를 포함하는 것을 금지하는 근거는 확인하지 않았다. 출력물이 독점적이거나 제3자 권리를 침해하지 않는다는 보장은 아니다.
- 저장소의 생성 기록에는 사람·글자·로고·워터마크를 넣지 않는 제작 지침이 있다. 이는 결과물 전수 시각 검토나 입력 참고 이미지의 권리 증명을 대신하지 않는다.
- 기존 목록의 46개는 이미지와 JSON을 섞은 수치였다. 실제 사례 이미지 파일은 38개로 정정했다. 캐릭터·앱 아이콘은 다른 경로이므로 이 수치에 포함하지 않는다.
- 앱 이용약관 검토안에 GPT 제작 설명용 이미지이며 실제 사용자 사진/문제 현장 증거가 아니라는 안내를 추가했다. 실행 중 AI를 사용하지 않는 것과 정적 AI 이미지 사용은 다르다.
- YouTube 영상을 복제하거나 임베드하지 않고 링크로만 연결한다. 쿠팡은 제휴 ID 없이 제품명 검색 링크다. 외부 서비스의 보증·제휴로 표현하지 않는다.

결론: 자체 제작 사실과 일반 약관 검토는 완료. GPT 생성만을 근거로 모든 이미지의 제3자 권리 검증을 일괄 완료했다고 표시하지 않는다. 알려진 침해 대상이 없는지 최종 자산을 검토하고 출시용 아이콘도 함께 확인한다.

근거: https://openai.com/policies/terms-of-use/ (출력물 권리·입력 권리·비독점성·인간 제작으로 오인시키지 않을 의무).

## 이메일

- 사용자 확인: 일반 개인용 Gmail, happytanglee@gmail.com. Workspace DPA·서울 고정 저장이 적용된다고 쓰지 않는다.
- 기술 확인: 앱은 mailto 링크만 제공한다. 검색어·사진·문의 문장을 메일 본문에 자동 첨부하지 않는다. 실제 발송은 사용자가 외부 메일 앱에서 선택한다.
- 새 앱의 자동 OpenAI/Supabase 전송 제거와, 문의자가 외부 메일 서비스를 사용하는 일은 별도 처리다. 개인정보 안내에서 둘을 분리한다.
- 일반 Google 정책은 수신 이메일을 포함한 콘텐츠 처리 및 해외 서버 처리를 설명한다. 이를 ‘미국만 저장’이나 ‘Google도 반드시 30일 내 모든 사본 삭제’로 바꾸지 않는다.
- 일반 Gmail 사용 자체가 금지된다고 판단할 근거는 확인하지 않았다. 반대로 외부 메일을 사용자가 직접 보낸다는 이유만으로 운영팀의 개인정보 처리 책임이 면제되거나 법적 국외 이전 요건이 자동 충족되는 것으로 해석하지 않는다.
- 법 제28조의8에서 이전에 해당하는 경우의 적법 근거·고지 요건은 실제 운영 역할에 맞춰 판단해야 한다. Google 정책 링크 하나로 모든 법적 검토를 대신했다고 보고하지 않는다. 개인정보 검토안 v3에는 확인된 사실만 반영했다.

운영 절차: 담당 유소원만 업무상 필요한 범위에서 확인 → 원본 문제 글·사진·민감정보 제출을 요구하지 않음 → 동의 없이 LLM/다른 팀 채팅에 전달하지 않음 → 처리 완료 후 30일 이내 운영팀 관리 사본을 휴지통까지 삭제 → 보존 의무 예외는 근거·기간 안내 → 열람/정정/삭제/처리정지 요청에 대응. 실제 삭제 및 계정 보안 설정은 이번에 조작하지 않았다.
