## 현재 동작

질문 입력 → 기기 내 단어·증상 비교 → 최대 5개 관련 사례 → 사용자가 선택 → 기존 B02/B03. 생성 답변·사진 첨부·인증·서버 평가·신고는 앱 경로에서 제외했다. 인터넷이 없어도 핵심 흐름을 차단하지 않는다. 쿠팡·유튜브는 사용자가 누르는 외부 링크로 유지했다. 유튜브 원격 썸네일 대신 기존 로컬 이미지를 표시한다.

CSV 행·열·ID·해결 방법·문의 문구는 변경하지 않았다. 기존 LLM·서버 소스와 기존 서버 정책 초안은 이력을 보존하되 현재 앱에서는 사용하지 않는다. 새로운 정책 화면은 information-local.json을 읽는다. 이메일 보관 문구는 기존 초안의 처리 완료 후 30일 기준을 유지했다. 외부 Notion 페이지는 수정하지 않았으며 이전 정책 링크는 현재 앱에서 숨겼다.

## 직접 확인할 항목과 한계

실제 Android의 비행기 모드에서 실행·검색·사례 열기·문의 문구 복사를 확인해야 한다. 이번 변경으로 APK를 다시 빌드·설치한 것은 아니다. 최종 설치본의 네트워크 기록 검증과 스토어 개인정보·데이터 보안 양식 갱신은 출시 전에 필요하다.

검색은 문장의 의미를 폭넓게 이해하는 AI가 아니라 사전에 정한 단어·동의어·증상 비교다. 모르는 표현은 놓칠 수 있다. 현재 등록되지 않은 싱크대 누수·바퀴벌레 같은 문제를 위해 사례를 새로 만들거나 다른 물건의 수리를 억지로 반환하지 않는다. 실제 사용자 질문으로 검색 사전을 점검할 필요가 있다.

사진 모델의 실행·정확도·임시 파일 정리·외부 전송 검증은 구현되지 않았다. 설명 문서의 후속 작업이다.
