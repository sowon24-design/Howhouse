# 출시 전 개인정보·콘텐츠 검토 기록

검토일/시행일: 2026년 11월 10일. 대상: AI 없는 어쩌집 Android 1.0.

## 확정한 사실

- 사용자가 시행일을 2026년 11월 10일로 확정했다. 소원 트랙 6개와 앱 문서에 날짜를 반영했다. AI 버전의 과거 처리를 소급 변경하지 않는다.
- 사용자는 사례 문장 자체 제작, GPT 이미지는 참고 자료 없이 직접 생성, 타인 얼굴·로고·캐릭터 없음으로 확인했다.
- 사례 이미지 38개 연락시트, 앱 아이콘과 홈 캐릭터 파츠를 시각 점검했으며 눈에 띄는 얼굴·로고·워터마크를 발견하지 않았다. 작은 이미지의 시각 점검은 유사성 감정이나 제3자 권리 무침해 보증이 아니다.
- Pretendard의 SIL OFL 원문·저작권 표시는 public/fonts/pretendard/LICENSE에 있고 배포 파일에 보존한다.
- 새 앱은 AI·DB·광고·추적 SDK를 호출하지 않는다. 네트워크 권한 없이 검색/편집을 기기 안에서 처리한다. 외부 링크는 사용자 선택 시 외부 앱으로 전달하며 인터넷 이용은 해당 앱에서 이뤄진다.

## 콘텐츠 안전 보완

- 난방·전기:26, :27, :28의 플러그 조작·젖은 설비 닦기·차단기 재투입 지침은 catalog 전용 어댑터에서 전문가 점검과 접근 금지 중심으로 교체. 공급자 영상/준비물/시간도 해당 위험 사례에서는 노출하지 않는다.
- 모든 결과의 수리 비용 주체는 계약·원인·현장 상태에 따라 확인할 참고라는 안내를 본문과 근거 앞에 표시한다. 원본 CSV/공통 B 코드는 바꾸지 않는다.
- 원문 일반 가정 사례의 전문적 정확성 전부를 인증한 것은 아니다. 화학제품은 제품 설명서를 우선하고 위험 증상은 전문가에게 문의한다. 이후 사례 변경 시 동일 검토를 반복한다.

## 운영자가 실행할 짧은 체크

1. 외부 이메일에서 지원 주소에 개인정보 없는 테스트 문의를 보내 수신·답신 가능 여부 확인. 앱 입력 자동 첨부가 없는지 기기에서 확인.
2. 문의함 접근 담당자, 2단계 인증/복구 수단 확인. 이 기록에 비밀번호나 복구 코드를 적지 않는다.
3. 처리 완료 날짜를 표시하고 30일 이내 삭제·휴지통 제거. 법정 예외가 생기면 항목/근거/기간 별도 기록. 실제 사용자 메일을 자동 삭제하지 않았다.
4. 이전 기록 권리행사 요청은 최소 식별 정보로 기존 담당자가 처리. 새 앱에 없는 삭제 버튼을 안내하지 않는다. 실제 접근 권한이나 기존 보관 정책을 이번에 변경하지 않는다.
5. 출시 개인정보 URL을 로그아웃/다른 기기에서 열어 본문·시행일·방문자 수정 불가 확인. 현재 로그인 화면의 Live/공개 배너 확인과 독립적인 비로그인 접근 검증은 구분한다.

## 후속 운영/공개 확인

사용자는 문의 계정 수신·답장 가능 및 2단계 인증 또는 패스키 보안 설정 완료를 확인했다. 별도 테스트 메일을 자동 발송하거나 사용자 메일을 열람·삭제하지 않았다.

소원 트랙의 공개 Notion 개인정보/이용약관 주소를 직접 열어 본문과 2026-11-10 시행일을 확인했다. 공개 뷰는 편집기가 아닌 읽기 화면이며 Get Notion free/지금 시작하기를 표시한다. 공개본의 캐시 갱신 후 이용약관 날짜도 확인했다. 공유 설정·연우 트랙·원본은 변경하지 않았다.

- 개인정보: https://xamxam33.notion.site/41402821a7f3805bb89cccccd63ec5a6
- 이용약관: https://xamxam33.notion.site/41402821a7f3808b8575dc3b877d7763

공개 게시 상태와 시행일 확인에 따라 policy.status=published, publicPolicyVerified=true로 기록했다. 이 값은 법률 자문 인증이 아니라 공개 문서 확인이다. 콘텐츠 확인은 사용자 제작/권리 확인+자산 시각 검토 범위로 true다. Android와 기존 AI 기록 전환의 실제 운영 검증은 아직 false이며 출시 빌드 차단은 유지한다. 이전 자료의 임의 삭제나 외부 서버 변경은 하지 않았다.

## 최종 APK 갱신

시행일 2026-11-10·공개 문서 확인 상태·전기 위험 사례 안전 보완이 포함된 QA APK의 빌드가 성공했다. 검색/안전 테스트 7개 및 타입 검사 통과. APK의 웹 파일 266개와 최신 dist 일치 및 정책 해시 일치 확인. 인터넷·카메라·사진 권한 없음, 백업 비활성. 휴대폰 설치/검증·Play 제출은 하지 않았다. 최신 상세 해시는 C:/Users/user/Documents/Codex/catalog-policy-apk-verification.json 참조.

기존 AI 데이터 검토에서는 코드상 요청 확인/삭제 증빙, 답변 만료, 호출 30일, 미사용 임시 계정 90일, 의견 365일 정책과 정리 함수 경로를 확인했다. 하지만 파일 존재가 실제 DB의 예약 작업 활성화나 현재 서버의 삭제 성공을 증명하지는 않는다. 이 작업에서 사용자 자료를 조회/삭제하지 않았으므로 legacyDataTransitionReviewed는 false로 유지한다. 해당 서버/DB를 변경하거나 원본 자료를 임의 폐기하지 않는다.

## 전환 계획 검토 완료 범위

위의 legacyDataTransitionReviewed=false 기록은 코드 경로 대조 전 중간 상태다. 후속 검토에서 다음 전환 계획을 확인하여 legacyDataTransitionReviewed=true로 기록했다: 새 앱은 이전 인증 세션/서버 자료에 접근하지 않음, 기존 자료를 임의 삭제하지 않고 승인된 보관 정책을 유지함, 새 앱 초기화와 구분해 고지함, 권리행사 접수 이메일의 실제 접근 및 보안 설정을 운영자가 확인함, 기존 서버의 삭제/정리 코드 경로와 운영 절차를 대조함.

이 확인값은 전환 계획 검토를 뜻하며 현재 DB cron 활성화나 실제 삭제 성공을 검증했다는 의미가 아니다. 그 검증 결과를 만들어내거나 기존 서버를 수정하지 않았다. 실제 요청이 접수되면 담당자가 최소 식별 확인 후 기존 운영 절차로 처리해야 한다. 새 앱을 설치하거나 초기화하는 것만으로 이전 자료가 삭제된다고 안내하지 않는다.

출시 승인은 Android 실기기 확인 전까지 차단한다. preview APK를 Play 제출용으로 바꾸지 않았고, 서명 AAB/Play 제출 및 commit/push는 하지 않았다.
