# YouTube 출시 전 최종 대조 — 2026-11-12

## 범위와 결론
현재 로컬 작업을 보존했다. UI·문구·키·클라우드 설정·출시 승인 값은 변경하지 않았다. 유료 호출·커밋·푸시·배포는 하지 않았다. 현재 구현을 무조건 준수 완료로 승인할 근거는 부족하다. 기능 QA 통과와 법적/제공업체 준수 판단은 구분한다.

## 확인된 구현
- 공식 원본 흰색 아이콘, 중앙 배치, 해당 영상 링크. 원본 투명 여백 유지. 재색칠 없음.
- 현재 정책 버전 확인 전에는 API 요청하지 않음. 첫 이용 약관/방침 확인 후 프로필에 정책 버전 저장.
- API 요청은 공개 영상 ID·프로젝트 키·공통 Android 패키지/서명 헤더. 닉네임·검색어·문의 문장·사진·로그인 토큰을 넣지 않음.
- Google에 IP·HTTP 정보 노출. credentials omit, no-store, no-referrer, HTTPS. 썸네일은 메모리 blob으로 표시하고 숨김/해제 시 정리.
- 개인정보 본문은 YouTube API 사용, Google 개인정보처리방침 링크, 요청/보관/삭제 범위와 미확인 사항을 안내한다.
- 소원 트랙 관련 공개 문서 4개 동기화와 직접 설치 APK 기능 검증은 이전 단계에서 확인했다. 그 후 정리한 정책 문장 1개는 최종 재빌드가 필요하다.

## 출처 표시 판정
브랜딩 지침은 watermark의 흑백 버전을 안내한다. 원본 흰색을 사용하는 것 자체는 문제로 확인되지 않았다. 공식 이미지 사용·클릭 연결·크기/원본 비율은 구현되어 있다.
다만 지침은 단색 배경 표시를 should로 권고하고, 충분한 대비·명확한 표시를 요구한다. 현재 투명 아이콘 뒤에는 매번 다른 영상 이미지와 20% 검정 오버레이가 있어 모든 영상에서 대비를 보장하지 못한다. 단색 배경 권고만을 절대 금지 조항으로 해석하지 않는다. 현재 투명 배치를 확실한 준수 완료로 확정할 수 없다는 판정이다.
최소 수정안: 썸네일·카드 크기·문구·중앙 위치·아이콘 원본 크기를 유지하고, 아이콘의 투명 여백 아래에만 불투명 검정 단색 배경을 둔다. 사용자 UI 유지 요청 때문에 이번에는 적용하지 않았다. 일반 글자 또는 작은 임의 로고로 바꾸지 않는다.
아이콘 대신 wordmark를 권하는 적용 기준도 있으나 지침의 should와 must를 구분한다. 아이콘이 이 앱에서 절대 금지라고 단정하지 않는다.

## 개인정보 판정
YouTube 개발자 정책상 자체 약관의 YouTube 약관 링크/구속 안내, Google 방침 링크, 실제 처리 설명, 사전 방침 수락을 구현에서 확인했다. OAuth 사용자 데이터가 없으므로 OAuth 철회 화면 요구를 임의 추가하지 않는다.
이 확인은 한국법상 적법한 국외 이전 동의의 성립을 뜻하지 않는다. Google 직접 수집과 운영팀의 국외 제공/위탁에 해당하는지, 적용 근거를 이 구현에 맞게 확인해야 한다. 국외 이전 동의를 근거로 삼는 경우 국가·수령자·목적·보유기간 등 법정 고지를 미확인이라는 표현으로 대체하여 완료 처리하지 않는다. IP 노출만으로 위법이라고 단정하지도 않는다.
Google 공개 일반 방침은 이 API 요청의 정확한 처리 국가·로그 보관기간을 확정하지 못한다. Google 일반 방침 링크와 어쩌집의 메모리 삭제는 Google 로그의 보관/삭제 증거가 아니다.
해결 경로: 요청 구조와 현재 고지문으로 국내 개인정보 전문 검토에서 적용 근거/필요 고지를 확인하거나, 자동 외부 썸네일 조회를 제거하고 사용자가 누르는 외부 영상 링크만 유지하는 제품 변경을 선택한다. 후자는 썸네일 UI가 달라지므로 임의 적용하지 않는다. 프록시 서버는 다른 처리·운영 책임을 추가하므로 자동 해결책으로 간주하지 않는다.

## AAB/비공개 테스트 준비
- 현재 승인 JSON은 false, 정책 status는 review 유지. 완료 사실이 없는 승인 값을 빌드 통과용으로 바꾸지 않는다.
- Play 버전 코드 최대값을 Console에서 확인한 뒤 중복 없는 코드 확정.
- 위 쟁점 해결 후 최신 정책을 웹/Android에 반영하여 Play 서명 SHA-1 설정으로 production 빌드.
- 소유자가 기존 업로드 키 비밀번호를 직접 입력해 서명. 키는 Git/보고서/로그 제외.
- AAB package/version/permissions/policy hash/서명 확인. 기존 QA APK·오래된 AAB를 제출본으로 재명명하지 않음.
- 실제 Play 설치본 썸네일 검증은 업로드 후 수행할 수 있으므로 사전 HTTP200 검사와 구분한다. 배포 전 승인 게이트가 실설치 검증을 요구해 순환하지 않도록 향후 검증 단계 정의를 명확히 할 것. 이번에는 게이트 코드를 변경하지 않음.
- 팀원이 작성하는 데이터 보안 설문은 자동 외부 요청이 있는 현재 구현 기준으로 대조. 로컬 검색/문장 편집은 기기 내 처리. Google 보관을 앱의 임시 처리와 동일시하지 않음.
- 테스터 12명 확보, 이메일 입력은 사용자 대기. 업로드/초대/검토 제출 미실행.

## 사용자 지정 Multiply 처리 후속
사용자 요청에 따라 src/youtube/source.css에서 기존 검정 오버레이를 opacity .2 / mix-blend-mode multiply로 지정했다. 오버레이를 중복 추가하지 않았고 썸네일 앵커를 isolation isolate로 분리해 흰색 출처 아이콘에는 블렌딩이 적용되지 않는다. 나머지 제품 UI와 문구는 변경하지 않았다.
디자인 검토용 페이지는 기존 로컬 이미지와 제품의 b02/source CSS를 이용해 카드 높이 200px에서 캡처했다. API 연결/개인정보 동의 실검증 화면이 아니며 로컬 이미지를 제품에 재도입한 것이 아니다. 실제 CSS computed 값 multiply / opacity 0.2 / isolate 확인. 사용자 화면 승인 대기.
20% Multiply는 단색 불투명 배경과 같지 않다. 공식 규칙의 should 권고와 대비 요구를 구분하며 이 변경만으로 전체 제공업체/법적 준수를 확정하지 않는다.
AAB 사전 검사 실행: readyForPlaySubmission false. 기존 승인/정책/Android 반영 확인이 남아 최종 AAB 서명은 미실행. Google 국가/로그 보유기간 및 국외 처리 근거는 여전히 미확정이며 새 사실 없이 수집 없음/무보관/적법 확정 문구를 추가하지 않았다.
