# PR 제목

무료 샘플 기본 모드 및 Android 실제 네트워크 단절·F02 복구 연결

## 변경 내용

Android에서 Wi-Fi·모바일 데이터를 꺼도 F02로 이동하지 않던 문제를 수정했습니다. 공식 Network 플러그인으로 시작·연결 변경·앱 활성화 시 OS 상태를 확인합니다. 일반 화면 복구에 분석 서버를 조회하지 않습니다.

- 웹·Android 모두 무료 샘플 기본. 개발용 도구에서 기존 사례/생성 결과 샘플을 선택하고 실제 API는 명시적으로 전환합니다.
- F02는 연결 회복 후 재시도를 눌러 복귀합니다. 분석 중 단절되면 취소하고 글·사진을 보관한 A02로 돌아가며 자동 재분석하지 않습니다.
- F02 Android Back은 백그라운드 전환입니다. 오프라인 재진입 시 F02를 유지합니다.
- Network 8.0.1과 Android 동기화 설정, 팀원용 실행 안내를 추가했습니다.
- B 화면 내부·분석 클라이언트·서버 로직은 변경하지 않았습니다. `src/analysis/ConnectivityBoundary.tsx`는 합의한 통합 제어 변경입니다.

## 검증

- 웹 build/typecheck, verify:foundations 통과.
- 앱 관련 Node 테스트 57개 통과.
- Android 동기화·assembleDebug·에뮬레이터 재설치 성공.
- Pixel 10 API 36.1: 글 입력 → 무료 샘플 A04 → 기기 Wi-Fi·모바일 데이터 끄기 → F02 확인.
- 끊긴 상태 재시도 시 F02 유지, Android Back 백그라운드 전환, 재진입 F02 유지 확인.
- 연결 복구 후 재시도 → 작성 글을 유지한 A02 복귀, 자동 재분석 없음 확인. 네트워크 원상복구.
- 개인 보고서·API 키·로컬 SDK 설정·서명 파일·APK는 포함하지 않습니다.

## 미완료·검증 제한

- 이번 실제 단절 검증은 글 입력 기준입니다. 사진 보존·B 편집 상태·컴퓨터 Wi-Fi만 끄는 경로와 실제 Android 기기는 별도 재검증 대상입니다.
- 네트워크 연결 판정은 분석 서버나 OpenAI 응답 성공을 보장하지 않습니다. 실제 유료 API는 호출하지 않았습니다.
- 개발용 모드 전환·샘플 도구는 APK에도 남아 있습니다. 출시 전 노출 정리가 필요합니다.
- 기존 번들 크기 경고와 npm moderate 취약점 4건은 별도 검토 대상입니다. 강제 의존성 업데이트는 하지 않았습니다.

## 팀원 적용

자기 작업을 보존한 뒤 담당 브랜치에 `origin/main`을 병합합니다. 폴더를 교체하지 않습니다. 병합 후 `npm ci`와 `npm run build`를 실행합니다.

Android 담당자는 `npm run android:sync` 후 Android Studio에서 빌드·Run합니다. 플러그인 추가가 있어 APK 재빌드가 필요합니다. 웹 개발만 하는 팀원은 `npm run dev`로 확인할 수 있습니다.

main 병합은 예슬이 검토 후 진행합니다.
