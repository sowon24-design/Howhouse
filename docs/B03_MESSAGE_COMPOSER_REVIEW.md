# B03 메시지 작성 변경 검토

- 기준: Figma `717:17987`, 2026-11-21 사용자 요청.
- 문장 블록 선택 시트를 제거하고 대상별 본문 직접 편집을 유지한다.
- 대상 탭은 해당 사례에 있는 수신 대상만 표시한다. 두 대상이 있으면 ‘누구에게 보낼까요?’ 아래 집주인·수리기사 탭을 표시한다.
- 메시지 보내기(primary)와 복사하기(pale)를 세로로 배치한다. 키보드가 열린 때 기존 20px 하단 간격 규칙을 유지한다.
- Android는 ACTION_SENDTO / smsto: / sms_body로 작성한 본문을 메시지 앱에 전달한다. 수신 번호는 전달하지 않는다. 최종 수신자와 발송은 이용자가 메시지 앱에서 결정한다. 기본 처리 앱이 없거나 여러 앱이 등록된 환경에서는 OS 선택 화면 또는 실패 안내가 나타날 수 있다.
- 메시지 앱을 열 수 없으면 본문을 유지하고 복사하기를 안내한다. 빈 본문은 실행하지 않는다. 성공을 ‘발송 완료’로 표시하지 않는다.

## 개인정보·권한·정책 대조

- 연락처 조회, 문자 읽기·직접 발송 권한을 추가하지 않는다. 서버/API 호출을 추가하지 않는다.
- 사용자가 보내기 버튼을 누르면 현재 편집한 본문을 선택된 외부 메시지 앱에 넘긴다. 외부 앱의 초안 저장·발송·처리 방식은 그 앱에 따른다.
- 2026-11-21 사용자 요청으로 앱 정책 및 Notion의 이용약관·개인정보 처리방침·개인정보 및 데이터 관리·서비스 제공 방식에 직접 편집, 복사, 외부 메시지 앱으로 본문 전달, 사용자 수신자 입력·최종 발송, 연락처 미조회 안내를 반영했다. 외부 앱의 초안 보관·전송·정보 처리는 해당 정책에 따른다고 명시했다. YouTube 관련 본문은 유지했다.
- 이번 작업은 본문 동기화다. 기존 동의 버전·시행일·출시 승인 값은 변경하지 않았다. 출시 시 개정 적용일 및 정책 버전/승인 자료와 최종 Android 번들의 일치 검토가 필요하다. 현재 설치 APK는 이 본문 수정 이전 빌드다.
- YouTube 코드·정책 안내·썸네일 동작은 수정하지 않는다.
- 기능 구현 확인은 정책 적합성 또는 Play 심사 승인 판정이 아니다.

## 확인

- TypeScript 검사 및 catalog-preview 웹 빌드 통과.
- 브라우저 412×910에서 대상 탭, 직접 편집, 대상 전환 후 본문 유지, 복사 버튼, 빈 본문 방지, 데스크톱에서 메시지 앱 미지원 안내 확인.
- 최종 발송이나 실제 수신은 검사 범위에 포함하지 않는다.

- Android debug APK 빌드 통과. 병합 Manifest에서 INTERNET 및 앱 내부 receiver 권한만 확인했으며 문자·연락처 권한은 없다.
- 캡처용 폰에서 CTA가 기본 메시지 앱의 수신자 선택 화면을 여는 것을 확인했다.
- 에뮬레이터에서 테스트 수신자를 선택한 뒤 원본 한글 본문과 줄바꿈이 메시지 작성란에 전달된 것을 확인했다. 실제 발송은 하지 않았으며 실물 기기별 메시지 앱 동작은 별도 확인 대상이다.
